# 椿 上位商品ラダー設計書（灰谷案・単独設計）

## 0. 設計思想：価格軸を「情報量」から「意思決定の代行度 × 時間のカバレッジ」に付け替える

店主の懸念は正しい。現行3,980円は約12,000字・8章で、個別性も処方箋も出し切っとる。この上に「もっと厚いPDF」を積んだら、客より先に店主自身が信じられん商品になる。売れんのは当たり前や。

答えは実測1に全部書いてある。納品後295通の需要の中心は「動いた盤面への即応」——つまり客が金を払いたいのは読み物やなく、「彼がこう来た、次どうする」を決める仕事や。一回品のPDFは納品した瞬間から現実とズレ始める。この構造欠陥こそが上位商品の原料になる。

そこで各価格の意味をこう置く。字数は一切増やさん。

| 価格 | 商品名（仮） | 客の人生に起きる変化 | 時間のカバー範囲 |
|---|---|---|---|
| 3,980円 | 個別鑑定書（現行のまま） | 分かる | 今の一枚絵 |
| 9,800円 | 動きの書 | 迷わず動ける | これからの90日（計画） |
| 16,800円 | 動きの書・二度視 | 動いた後も外さない | 90日＋盤面が動いた瞬間（即応） |
| 14,800円 | 岐路の三夜 | 決められる | 節目の一点を深く |
| 29,800円 | 四十五夜 | 考える仕事ごと預けられる | 45日間、向こうから運ばれる |

覚え方は一文や。「3,980円は彼が分かる。9,800円は動き方が決まる。16,800円は動いた後も見てもらえる。14,800円は道が決まる。29,800円は運転ごと預けられる」。どこにも「厚い」が出てこん。これが増量商法に見えん骨格や。

なお商品名はいずれも願望成就（復縁・成就・結ばれ）を示唆せん語だけで組んだ。仮置きの「結び直し」は縁が結び直される＝結果示唆に片足入っとるから、L3は「四十五夜」に改名を進言する（月詠みと兄弟の月の語彙で、ブランドも通る）。

## 1. L1中位 9,800円「動きの書（うごきのしょ）」

### 果たす仕事
3,980円で買えないもの：現行の処方箋章は「焦らず様子を見ろ、来たらこう受けろ」という方向性の助言や。日付は入っとらん。動きの書は、その子の状況（別れて何日・音信不通の長さ・彼の性質）から起こした「日付入りの90日の暦」と「発動条件付きの文面3本」を渡す。読んで理解する商品やなく、カレンダーに従って手を動かす商品や。

月詠みで代替できないもの：月詠みは聞いたら返ってくる場所や。90日を見通した日付入りの作戦図は、月10通の往復と週1の視立てでは物理的に組めん。しかも暦は「聞く前に決まっとる」。性質が逆や。逆に、惚気と不安の受け止め（田中麻衣さん需要）は暦では代替できんから、月詠みを食わん。

### 納品物の具体（届く順）
1. 個別鑑定書PDF（現行の8章・約12,000字。ここは1字も増やさん）
2. 九十日の暦：1枚もの画像（スマホ壁紙比率・LINEで保存可）。90日を「静の期間」「送ってええ窓」「仕掛けの窓」「地雷日（記念日・彼の繁忙など聞き取りから）」で塗り分け、日付で明記。＋解説文約2,000字（なぜその窓か）
3. 文面の三手：場面別の実物文面3本。(あ)彼から連絡が来た時の受けの一手 (い)こちらから口火を切る一手 (う)沈黙が続いた時の様子見の一手。各文面に「出す条件」「出した後にやったらあかんこと」を添える
4. 納品文（読む順の指定：三章→五章→暦→文面の順。現行の体験設計の実測勝ちパターンを踏襲）

顧客体験シナリオ：納品の夜に鑑定書を読む（分かる）→暦を待受けに保存する（伴彩香さんの「お守り再読」行動が毎朝の儀式になる）→18日目、暦の「送ってええ窓」が来る→文面(い)を自分の言葉に直して送る→迷いの時間がゼロ。客は「視てもらった」やなく「動けた」を体験する。

### 生産の実務（QA15分に収める内訳）
鑑定書8分（現行と同じ）／暦3分／文面3本で3分／納品文1分＝15分。暦は生成時に機械lint（過去日の排除・窓の重複禁止・ヒアリング回答との日付整合・禁句チェック）を通してから店主に渡す仕組みにする。店主の目視は「この子の状況と矛盾せんか」だけ。暦と文面は定型構造やから、散文よりQAが1字あたり速い。確定時間表の15分/冊を破らん。

### 売り方
買う瞬間（本人から「どうしたらいい？」が出た時）に、3択を一度だけ・一通で見せる。文面案（Markdownなし・算用数字・不安煽りなし）：

```
その一手は、無料の視方じゃ答えられん。ちゃんと視るなら、形が3つある。

・個別鑑定書 3,980円
彼の本音と、二人の縁の正体を底まで視る。読んで分かる用や。

・動きの書 9,800円
鑑定書に、あんた専用の90日の暦と、場面別の文面を3本付ける。いつ動いて、何て送るかまで決めて渡す。もう迷わん用や。

・動きの書・二度視 16,800円
動きの書に、視直しの札を1枚付ける。90日のうちに彼が動いた時、その札を出してくれたら、新しい盤面でもう一回視て、暦も引き直す。動いた後まで見る用や。

視る深さはどれも同じや。違うのは、読んだあとにあんたが迷うかどうか。
急がんでええ、決まったら言い🌙
```

「視る深さはどれも同じ」と言い切るのが肝や。深さで差を付けん＝下位を買った子も傷つかんし、上位は「量」やなく「迷いの消え方」で選ばれる。

### 増量に見えない理由（客の一言）
「日付と文面まで決めて渡してくれるから」。読む量は増えとらん。増えたんは紙の種類（暦という画像1枚、条件付きの台本3本）や。

## 2. L1上位 16,800円「動きの書・二度視（にどみ）」

### 果たす仕事
3,980円にも9,800円にも無いもの：納品後の未来に対する備えや。一回品の最大の弱点「納品した瞬間から現実とズレる」を、商品の中に「二度視の札」として折り込む。90日以内に盤面が動いた時（彼から連絡が来た・会った・沈黙が30日続いた等）、客は札を1回だけ切れる。切ったら48時間以内に、新しい盤面の視直し書（約4,000字）と引き直した暦が届く。

月詠みで代替できないもの：月10通のチャットで4,000字の視直し書と暦の引き直しは運べん。会話は即応、視直しは文書や。形式が違う。しかも1回きりやから「実質し放題」にもならん。tomokoさん（購入当日に自分から追加課金を申し出た）が拾えんかった需要の正式な受け皿がこれや。

### 納品物の具体
動きの書一式＋「二度視の札」1枚（札も画像1枚で渡す。財布に入れる感覚で保存させる）。納品文に使い方を書く：

```
札の使い方はこうや。90日のうちに彼が動いた時、ここに「二度視」て送り。
2日以内に、新しい盤面の視直しと、引き直した暦を届ける。
1回きりの札やから、ここぞっちゅう時に切りや。
```

顧客体験シナリオ：38日目に彼から突然LINEが来る→客はパニックにならず「札がある」と思い出す→「二度視」と送る→48時間以内に視直し書＋新しい暦→この時の客の体感は「買った時より今の方が価値がある」。一回品なのに関係が生きとる。そして札を使い切った瞬間が、月詠み・四十五夜への天然の導線になる（後述）。

### 生産の実務
初回QA15分（動きの書と同一）＋札の発動時に10分（視直し書は短く、lint済み）。生涯25分/件。発動は「二度視」のキーワード受付→既存のオーダー照合の半自動フローに乗せる。48時間SLAやから店主は毎日のQA枠にまとめて処理できて、時間が客に振り回されん。仮に16,800円が日1件・札の消化率7割でも、追加負荷は日7分。封筒に対して誤差や。

### 売り方
上の3択文面に同梱済み。追加の売り込みは一切せん。札の消化後の納品文の締めだけ、一度だけ橋を架ける：

```
札はこれで使い切りや。この先も盤面は動く。
月に一遍の様子見でええなら月詠み、毎週隣で運んでほしいなら四十五夜っちゅう道もある。
要る時だけ言い。
```

### 増量に見えない理由（客の一言）
「彼が動いた後に、もう1回視てもらえる札が付いとるから」。＋7,000円の中身は紙やなく権利や。増量とは説明のしようがない。

## 3. L1.5 特別鑑定 14,800円「岐路の三夜（きろのみよ）」

### 果たす仕事
これは新規向けやなく、再接触率91%の既購入者と月詠み会員の「節目」専用商品や。初回の3択には絶対に混ぜん（4択は死ぬ）。

3,980円で買えないもの：鑑定書は「彼と縁の地図」やが、「あんたの決断」は扱っとらん。岐路の三夜の仕事は、待つ・動く・引くの三叉路で決められん状態を終わらせること。ウチの信条で言えば、これが一番純度の高い「意思決定の代行」や。

月詠みで代替できないもの：決断級の思考は10通の往復に乗らん。会話は即応のための道具で、決断には文書と儀式が要る。月詠みは日々の護衛、岐路の三夜は節目の軍議。棲み分けは一言で説明できる。

### 納品物の具体（3晩連続・毎晩20時に届く連載形式）
- 一夜目「縁の書」約4,000字：二人の縁の正体。続く縁か、燃えて終わる縁か、彼にとってあんたは何なのか。末尾に一問の宿題（「今夜これだけ考えとき」）
- 二夜目「潮の書」約3,500字＋潮見表画像1枚：時期。待つならいつまで待つ意味があるか、動くならどの窓か。冒頭で一夜目の宿題に答える形で始まる
- 三夜目「手の書」約3,500字：三つの道（待つ・動く・引く）それぞれの手順・文面・引き返す線。最終ページに「判（はん）」＝椿の見立てを1枚画像で。「ウチならこの道を取る。理由は三つ」＋「ただし決めるのはあんたや」の一文（見立てであって断定・保証にせん。消契法ガードを文中に構造として埋める）

顧客体験シナリオ：申込→翌晩から3晩、20時に1冊ずつ届く→客は3日間「今夜届く」を待って暮らす（読む体験そのものが儀式になる。仮置きの「3部作」を、同梱3ファイルやなく3晩の連載にすることが増量との決定的な違いや）→3晩目に判を保存する→迷いが「材料が揃った上の選択」に変わる。

### 生産の実務
3冊＋判は受注時に一括生成→店主は一括QA25〜30分（縁8分・潮8分・手と判10分・予約設定2分）→LINEの予約送信で3晩自動配信。確定時間表の25〜30分/件そのままや。配信に人手ゼロ。

### 売り方
売り込みは禁止。検知は「決断語彙」や。「諦めた方がいいですか」「もう待つべきか分からん」「どうしたらいいか分からん」が本人から出た時だけ、一度だけ扉を見せる：

```
あんたが今聞いてるんは、返信の話やないな。この縁を続けるかどうかの話や。
それは1通のやりとりで答えるもんやのうて、腰据えて視るもんや。

そういう子のために、岐路の三夜っちゅう鑑定がある。14,800円や。
一夜目に縁の正体、二夜目に潮の満ち引き、三夜目に三つの道の手順。
3晩に分けて届けて、最後にウチの見立てを判として1枚で渡す。
決めるのはあんたや。ただ、決められるだけの材料は全部揃える。

聞きたなったら言い。急かしはせん🌙
```

不安を作っとらん。客が既に持っとる迷いに名前を付けただけや（実測：本人発火の成約34.8%対こちら発火1.7%。この商品こそ本人発火でしか売ったらあかん）。

### 増量に見えない理由（客の一言）
「3晩かけて、待つか動くか引くかの判まで出してくれるから」。鑑定書の続編やなく、別の仕事（決断）の商品やと客自身が言える。

## 4. L3 29,800円「四十五夜（しじゅうごや）」（20席上限）

### 果たす仕事
月詠みとの差は方向や。月詠みは聞いたら返ってくる（受け身・従量）。四十五夜は聞かんでも向こうから届く（先回り・番組）。45日間、「今週どうするか」を考える仕事を椿が引き受ける。29,800円の中身は情報やなく、迷う時間の消滅や。そして45日で必ず終わる。終わりがある商品は、し放題の再発明にも、依存の飼育にもならん。

### 納品物の具体（45日の番組表）
- 初日「開帳の視立て」：現在盤面の精査＋45日の行程表画像1枚（6週それぞれの局面名入り）。既購入者は鑑定書の内容を引き継いで作る
- 毎週月曜20時「週の一手」×6回：その週の盤面視立て（800〜1,200字）＋今週やる一手（1つ）＋今週やったらあかん一手（1つ）＋必要な週は文面1本。客が何も聞かんでも届く
- 文面の添削枠：週3本まで（上限明記。し放題にせん）。原文への朱入れ形式
- 45日目「終いの書」：45日の総括（あんたはこれだけ動けた、の記録）＋この先90日の暦＋卒業の口上（そのまま終わってええ。月の様子見が要るなら月詠みがある）

顧客体験シナリオ：客の45日は「月曜の晩に一手が届く」のリズムで流れる。火〜金は一手を実行し、添削枠で文面を整え、日曜に翌週を待つ。45日目、終いの書で自分の動いた量を見せられて卒業する。「ずっと繋いで金を取る」の真逆をやる。これが席の回転も生む（45日で20席が回る＝月あたり約13席の新規を入れられる）。

### 生産の実務（満席20席での週次負荷）
- 週の一手：20人×QA5分＝100分（月曜朝に一括生成→一括QA→20時予約送信）
- 添削：上限60本/週、消化率5割想定30本×2分＝60分
- 開帳・終い：回転で週約3人×25分＝75分
- 計 約4時間/週（最悪でも5時間）。売上は20席×29,800円÷45日≒日13,200円。時間単価で見て一番強い商品や。

### 売り方
入口は4つだけ。(あ)岐路の三夜の判が「動く」やった子の感想返信時 (い)二度視の札を使い切った子 (う)月詠み会員が月10通を使い切って追加を求めた時 (え)tomokoさん型の「追加でお金払います」申し出。文面案：

```
四十五夜はな、あんたが聞く前に、ウチから届く方の鑑定や。
毎週月曜の晩に、その週の盤面と、今週やる一手、やったらあかん一手を送る。
あんたの文面の直しも週3本まで見る。45日で一区切り、終いに次の90日の暦を渡して卒業や。

29,800円。席は20しか置いてへん。ウチの目がちゃんと届くんが、そこまでやからや。
今は◯席空いとる。入るかどうかは、ゆっくり決めてええ🌙
```

20席は演出やなく実在するQA上限やから、希少性の提示が嘘にならん（景表法的にも安全）。

### 増量に見えない理由（客の一言）
「45日間、聞かんでも毎週向こうから一手が届くから」。月詠み（199円/日・聞いたら返る）との差も「向きが逆」で一言説明できる。

## 5. 時間封筒の総勘定（目標日給7〜8万円時の想定負荷）

L1日5件（内訳4:4:2）×15分＝週8.8h／二度視発動 週約1.2h／岐路の三夜 日1件×30分＝週3.5h／四十五夜 満席で週4〜5h／月詠み承認＋雑務 週約3h。合計約20.5〜21.5h＝封筒19〜23hの上縁内。しかも岐路は受注数、四十五夜は席数で蛇口を絞れるから、溢れる前に止められる。売上側は同条件でL1約44,000円＋岐路14,800円＋四十五夜13,200円＝日約7.2万円＋月詠み。目標日給に構造として届く（到達シナリオであって約束やない）。

必要な追加開発は4点だけ、全部既存スタックで作れる：(1)暦ジェネレータ＋日付整合lint (2)LINE予約送信（三夜連載・週の一手）(3)「二度視」キーワード受付フロー (4)四十五夜の週次QAキュー画面。人間偽装の追加は一切無し（音声・手書き・動画は使わん。全部テキストと画像や）。

## 6. この設計の最大の弱点（白状）

日付を売るということは、外れが記録される商品を売るということや。

現行の鑑定書は散文やから、外れが特定されにくい「お守り」でおれた。せやけど九十日の暦は「8/22〜29が窓」と書く。窓で動いて何も起きんかった時、失望は日付に紐づいて記録され、責任の所在が椿一点に集まる。防波堤は張ってある（暦は「彼がこう動く」の予言やなく「あんたが動きやすい窓」＝本人の行動指定で書く原則。自分の行動なら実行自体が成果になる）。それでも客は必ず日付を予言として読む。外れた客に二度視や月詠みが受け皿として機能するほど、外から見た形は「外れを追加課金で回収する回路」に近づいていく——消契法対策で潰したはずの構造の、薄い影がラダーの芯に入っとる。ここの言葉の運用を一度でも間違えたら、この設計は一番高いところから壊れる。
