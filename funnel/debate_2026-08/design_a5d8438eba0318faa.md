# 高額商品スペック設計書（三崎案）

設計者としての立場を先に言う。私は「厚みで価格を説明する商品」を一切作らない。3,980円の鑑定書は既に12,000字・8章で読み物として出し切っており、この上に文章を積むのは増量商法にしか見えないし、QA時間も文章量に比例して膨らむ。つまり増量は「売れない」と「封筒を破る」を同時に引き起こす最悪手や。

代わりに、価格の担い手を文章量から次の4つに移す。

- 視る時間の長さ（今だけ→90日）
- 動いた盤面への正式対応「権利」（回数・期限つき）
- 一点の決行への特化（日取りと台本）
- 期限つきの行程構造（週次の定点）

この4つはどれも「スキーマが固定された構造物」で作れる。QAコストは自由文の量に比例するから、上位商品ほど構造物で積めば、価格は上がるのにQA時間はサブリニアにしか増えない。増量に見えない理由と時間封筒に収まる理由が、同じ一つの原理から出る。これがこの設計の背骨や。

実測の裏付けも言うておく。295通の内訳が示す需要は「静的な読み物」やない。27%が動いた盤面の解釈、多数が次の一手と文面。つまり客が金を払いたいのは納品後に盤面が動いた瞬間であって、納品時の紙の厚さやない。上位商品は全部「動いた後」を売る。

## 共通部品「視直し」の仕様（先に定義する。上位価格の芯であり、月詠みを食わない線引きの要）

- 定義：納品後45日以内、「盤面が動いた」1件につき1回使える正式な再鑑定文書。トリガー例＝彼から連絡が来た、会う日が決まった、送ったのに返事がない、共通の知人経由で動きがあった
- 受付：LINEで「視直し」と送る→定型3問（何が起きた・いつ・どう返したいつもりか）が半自動で返る（既存ヒアリングの型を流用）
- 納品物：固定4段・1,000〜1,200字の文書1枚（画像またはPDF）。「何が起きたとウチは視るか」「彼側から見た意味」「次の一手（いつ・何を）」「今やらんこと」
- 納期：受付から48時間以内。日次のQAバッチに乗せる
- QA：4段スキーマ固定・禁止語lint通過後の目視で5分/件
- 月詠みとの線引き（購入時に言い切る。後から線を引かない原則の踏襲）：視直しは文書であって会話やない。3問に答える形でしか受けん。1件の動きにつき1回。回数と期限が決まっとる。会話で続けたくなったら月詠みの領分
- 単品販売はしない。権利を使い切った人の受け皿は月詠みか橋掛かり。ここを崩すと従量労働の再発明になる

## L1中 9,800円「潮見の帖」

**1. 果たす仕事**：この先90日を、日付で待てるようにする。3,980円で買えないもの＝時間の地図。現行8章の処方箋は「いつ・何を」を書くが、90日を一望するカレンダーは無い。月詠みで代替できないもの＝月詠みは尋ねた時に返ってくる会話で、90日を俯瞰する一枚の地図は永久に出てこない。相談の大半が「待つ」局面（音信不通・別れて待つ）である以上、「待ち時間に形を与える」のは構造的に合う仕事や。

**2. 納品物と体験シナリオ**
- 見立ての帖（現行8章PDF・変更なし）
- 別冊「潮見表・九十日」（PDF3〜4ページ）：納品日から90日を13週に割り、各週に潮（動く週・待つ週・凪の週）と一言。動くのに向く日を計8〜10日、日付で明記。巻末に「その日が来たら何をするか」を第五章の処方箋と連動させて置く
- スマホ壁紙サイズのカレンダー画像1枚（潮見表の要約面）。伴彩香さんの「不安になったら読み返す」行動の受け皿を、最初から持ち歩ける形で渡す
- 視直し1回（45日内）
- 納品文で読む順を指定：「第三章→第五章→潮見表。潮見表はスマホに貼っとき」。以後90日、客は「次の動く日」を持って待てる

**3. 生産の実務**：生成は既存パイプラインに潮見表テンプレを1本追加（週×潮×一言のスキーマ固定、日付必須、禁止語lint、処方箋との整合チェックを機械側で先に走らせる）。QAは自由文でなく照合が中心＝鑑定書との矛盾と日付だけ見る。基本15分＋潮見表5分＝20分/件。

**4. 売り方**：既存の買う瞬間（本人が「どうしたらいい？」を言った後）に、値段やなく「どこまで視るか」で3択を出す。文面例（プレーンテキスト・そのまま使える温度）：

```
その一手は、無料の視方じゃ答えられん。ちゃんと視るなら三つある。
今の彼とあんたを視て、処方箋まで出すのが見立ての帖。3,980円や。
そこに九十日ぶんの潮見表をつけて、いつ動いていつ待つかを日付で出すのが潮見の帖。9,800円。
さらにこの先、盤面が動いた時に三度まで視直す権利と、彼に送る文面の型までつけたんが構え。16,800円や。
どこまで視てほしいかで選び。急がんでええ、決まったらおいで🌙
```

**5. 増量に見えない理由（客の一言）**：「今だけやなくて、九十日ぶんの動く日と待つ日が日付で分かるから」。紙の厚さやなく、視ている時間の長さが価格差や。

## L1上 16,800円「潮見の帖・構え」

**1. 果たす仕事**：動いた瞬間に正式に視直してもらえる権利を持って待てる。tomokoさんが購入当日に「追加料金払うので追加を」と自分から言うた、あの需要の正式な受け皿や。3,980円で買えないもの＝納品後の盤面変化への正式対応（現行は納品した瞬間から状況とズレ始める一回品）。月詠みで代替できないもの＝月詠みは10通の会話の断片、視直しは1枚の再鑑定文書。会話と文書は別の商品カテゴリや。

**2. 納品物と体験シナリオ**：潮見の帖の全部に加えて、
- 視直し3回（45日内。共通仕様どおり）
- 「受けの型」（PDF3ページまたは画像7枚）：その人の状況と彼の性質に合わせて生成する場面別文面7場面。例＝彼から短文が来た時の受け、既読無視明けの再送、会う約束の切り出し、当日の締めの一言、謝られた時、そっけない返事への返し、動かんと決めた時の自分への宣言文。各場面、そのまま送れる第一稿＋「やらんとき」1行
- お守り札1枚（画像）：その人の鑑定書から一番効いた一文（実測で最頻出の「彼の今の本音」章の核心句）を椿の言葉で1枚に。再読行動の受け皿第二弾
- 体験の流れ：納品時に「型は保存しとき。使う日が来たら開く。盤面が動いたら『視直し』て送り。三度までウチが正式に視る」と権利を宣言して渡す。客は45日間「動いても独りやない」状態で待てる。これは保証やなく、対応枠の事前購入や

**3. 生産の実務**：納品時QA＝潮見の帖20分＋受けの型3分（テンプレ骨格固定・変数差し込みのトーン確認のみ）＋札1分＝24分/件。後日の視直しが5分×最大3回、45日に分散して乗る。

**4. 売り方**：上の3択文面で同時提示。加えて、梅・竹の購入者が納品後に動きを報告してきた時（295通の27%の瞬間）が構えの存在を知らせる場面になるが、単品売りはせんので、そこでは橋掛かりか月詠みに送る（後述の分岐ルール）。権利を使い切った客への橋渡し文面例：

```
構えの視直しは三度まで。今ので使い切りや。ようけ動いた四十五日やったな。
この先も動くたびに視てほしいなら、そこからは月詠みの領分になる。月5,980円で月10通と、週にいっぺんの視立てや。
入らんでもやれる。潮見表は生きとるから、まずはあれの通りに動き。
```

**5. 増量に見えない理由（客の一言）**：「動いた時に三度まで視直してもらえる権利がついとるから」。読む物やなく、使う権利と道具。財の種類が違う。

## L1.5 14,800円「橋掛かり」（特別鑑定）

**1. 果たす仕事**：一つの決行（音信不通からの再接触・会う日・気持ちを伝える・引くと決める、のどれか一つ）を、日取りと当日の台本つきで迎える。仮置きの「相性・時期・具体策の3部作」の骨格は残すが、全部を一つの決行日に向けて束ね直す。3,980円で買えないもの＝全体を視る鑑定に対する、一点を深掘る鑑定。月詠みで代替できないもの＝10通のトークでは日付3候補と分岐台本の束は物理的に作れん。週1視立ては定点観察であって、決行の設計図やない。

**2. 納品物と体験シナリオ**
- 追加ヒアリング5問（前回鑑定からの経緯・決行の中身・彼の最近の様子・自分の腹積もり・譲れん一線）。申込時に決行を一つだけ選ばせる。要望を散らかさせないのは生産の分散を防ぐためや
- 3部作PDF計6〜8ページ、読む順指定つき：
  - 一の帖「噛み合わせ」：この決行の場面に限定した、ふたりの噛み合わせの再解剖。どこが噛み合い、どこで事故りやすいか。基本鑑定の要約再掲は禁止（lintで重複検知）
  - 二の帖「日取り」：決行に向く日を3日、避けたい日を2日、45日内に日付と理由つきで置く
  - 三の帖「当日の運び」：そのまま送れる第一稿＋彼の返し3分岐（すぐ返る・遅れて返る・返らん）それぞれの受け方と「やらんこと」。会う決行なら入り・話す順・切り上げ方
- 事後の視直し1回つき（決行から7日以内）。結果を報告してもらい、盤面更新の文書を返す。ここが体験の山場で、次（月詠み・水先）への自然な橋になる

**3. 生産の実務**：ヒアリング半自動（既存の型を流用）、生成自動。QAは5問との照合・3部作の整合・日付チェックで25分、事後視直し5分、計30分/件。確定済みの25〜30分枠にちょうど収まる。

**4. 売り方**：売る瞬間は2つ。①納品後の動き報告で、動きが「日付の絡む決行」型やった時（会う日が決まった・再接触したい）。継続的な不安・気持ちの相談なら月詠みへ、という分岐ルールを店主のダッシュボード運用に固定する。②潮見表の「動く日」の7日前の自動チェックイン（「そろそろ潮の変わる週や。彼のこと、なんか動きあるか？」）で決行の言葉が出た時。文面例：

```
会う日が決まったんやな。ほなここからは、その日のためだけに視るやり方がある。
橋掛かりいう特別鑑定や。ふたりの噛み合わせをその場面だけで視直して、日取りの向き不向きと、当日の言葉の運びまで一冊にする。終わったあとの視直しも一回つく。14,800円。
やるかどうかはあんたが決めることや。その日が来る前に言うてくれたらええ🌙
```

**5. 増量に見えない理由（客の一言）**：「全体の鑑定やなくて、その日のための鑑定やから」。範囲を広げた商品やなく、範囲を絞った商品。絞る方が高い、という価格論理は美容医療でも弁護士でも通っとる普遍の型や。

## L3 29,800円「水先 四十五日」

**1. 果たす仕事**：45日間、毎週決まった日に盤面を見てもらいながら進む「行程」。3,980円で買えないもの＝時間の中の伴走そのもの。月詠みで代替できないもの＝月詠みは期限なしの居場所（話したい時に話す）、水先は起点と終点と週ごとの主題がある行程プログラム。居場所と行程は買う動機が違う。卒業時の受け皿が月詠みになるから、食い合いやなく送客の関係になる。

**2. 納品物と体験シナリオ**
- 0日目「乗り出しの帖」（PDF6〜8ページ）：現在地の盤面図1枚＋45日の行程表（週ごとの主題を個別生成。例＝一週目 整える、二週目 観る、三週目 試す…）＋お守りページ（不安の夜に開く専用の1ページ。この人の鑑定から抜いた言葉で組む。夜中の不安連投を人的対応やなく紙で受ける装置や）
- 毎週決まった曜日に「週の潮見」（800〜1,000字の文書、45日で6回）：先週の報告への受け止め＋その週の潮＋今週の一手ひとつ。受け止めを文書の冒頭に固定で入れることで、「不安の受け止め」需要を会話でなく定点文書で吸収する
- 週1の報告フォーム（定型3問：今週あったこと・彼の動き・来週やるつもりのこと）。LINEで型文が届き、返信で埋める
- 文面添削 週2通まで（「添削」と送る→原文を貼る→直しと理由1行が返る）
- 45日目「舫いの帖」（PDF4ページ）：総括＋この先90日の潮見表＋月詠みの案内を一度だけ
- 行程外の自由トークは受けない。申込時に言い切る：「毎日話す場所やない。週にいっぺん、ウチが盤面を見て一手を決める場所や。毎日話したいなら月詠みが合うとる」

**3. 生産の実務（20席満席時・週あたり）**
- 週の潮見 20枚 × 4分（固定スキーマ・報告フォームとの照合のみ）＝80分
- 添削 実効稼働5割と見て20通 × 3分＝60分
- 乗り出し・舫い 平均3件/週 × 15分＝45分
- 合計 約185分/週 ≒ 3.1時間/週。売上は20席 × 29,800円 ＝ 596,000円/45日 ≒ 月39.7万円。時給換算およそ3万円超。20席上限は演出やなく実在の運用制約やから、席数を正直に言うことがそのまま希少性の訴求になる

**4. 売り方**：瞬間は3つ。①橋掛かりの事後視直しを返した直後（決行の後こそ定点が要る局面）。②鑑定書納品後、「待つ」局面の人から不安の連投が来た時に、月詠みと並べて出して自己選択させる。③潮見の帖の90日を走り切った人への締めの案内。文面例：

```
あんたの盤面、ここからの四十五日は勝負所いうより我慢所や。
一人で待つんがしんどいなら、水先いうやり方がある。
週にいっぺんウチが盤面を見て、その週の一手をひとつだけ決める。送りたい文面があれば週2通まで見る。四十五日で区切る。29,800円で、席は20までしか取らん。ウチの目がちゃんと届く数がそこまでやからや。
毎日話したいなら月詠みの方が合うとる。行程を決めて進みたいなら水先や。どっちでもええし、どっちも選ばんでもええ🌙
```

**5. 増量に見えない理由（客の一言）**：「四十五日、毎週決まった日に見てもらいながら進めるから」。読む物への課金やなく、期間と構造への課金。

## 時間封筒の検算（目標スケール時の想定ミックス）

前提：L1計6件/日（梅60%・竹25%・松15%）、橋掛かり0.7件/日、L3満席20席、視直し権利の実効消化率6割。

| 項目 | 計算 | 分/日 |
|---|---|---|
| L1 QA | 3.6×15 ＋ 1.5×20 ＋ 0.9×24 | 105.6 |
| 視直し消化 | (1.5×1＋0.9×3)×0.6×5分 | 12.6 |
| 橋掛かり | 0.7×30 | 21 |
| L3 | 185分/週 ÷ 7 | 26.4 |
| 合計 | | 約166分/日 ≒ 19.3時間/週 |

封筒の上縁19〜23時間の内側。売上side：L1 44,148円/日＋橋掛かり10,360円/日＋L3 約13,200円/日換算 ≒ 6.8万円/日＋月詠みサブスク。目標日給7〜8万円の射程に入る。ただし既存の月詠み返信・照合作業が別枠で乗るから、L1が8件/日を超える局面では竹・松比率の監視とQA分数の実測を義務にする。監視指標は一つでええ：「週のQA実測分 ÷ 売上」。これが上がり始めたら構造物のlintを増やす。

運用の追加開発は4点だけ（潮見表テンプレ、視直し3問フォーム、週次報告フォーム、日付・重複lint）。全部一回作れば終わる複製可能資産で、こはく側にそのまま配れる。商品を「テンプレ＋権利＋行程」で組む設計は、多店舗展開の原価をゼロに近づける。

なお、梅から竹への差額アップグレードはやらない。決済と照合が煩雑になるだけや。後から時間軸が欲しくなった梅の客の受け皿は、橋掛かりと月詠みで足りる。

## この設計の最大の弱点（白状）

日付を売る商品は、外れが可視化される。これや。

現行の「彼の本音」は構造的に反証されにくい商品やが、潮見表の「動くのに向く日」や橋掛かりの「日取り3候補」は、日付を明記した瞬間に検証可能になる。「あの日に動いたのに何も起きんかった」という体験は、保証表現を一切使わんでも客の中に静かに積もり、上位商品ほど信頼を削る速度が速い。表現を「向き不向き」「潮」に留める・的中やなく行動の区切りとして渡す、という緩和はこの設計に織り込んだが、時間軸を商品の芯に据えた以上、この検証可能性リスクは構造的に消えん。ラダーの主柱である潮見の帖が一番この弱点を背負っとる、というのが正直なところや。
