# Instagram アカウント設計（椿）

★2026-10-09 作成。これより前に書いた案は、二つとも実測で否定されたんで捨てた。
　　・「プロフィールが本体」→ Threadsで固定・プロフ誘導は80本で1件（03_winning_elements.md）
　　・「入口はDM一本」　　→ Threadsで DM誘導は61本で5件（1本0.1件）
　　この二つで141本使うて、獲得6件やった。同じ型をInstagramで繰り返すとこやった。

---

## 1. コンセプト（★ここは動かさん）

LINEの相談90日ぶん、1,598人・19,390発言を数えた実測から出した。

| 相談者が自分から書いた言葉 | 人数 | 割合 |
|---|---|---|
| **既読・未読・ブロック** | **649人** | **40.6%** |
| 待つ・待てない | 318人 | 19.9% |
| いつ／時期 | 243人 | 15.2% |
| どうしたらいい | 230人 | 14.4% |
| 彼の気持ち・本音 | 241人 | 15.1% |
| つらい・しんどい | 197人 | 12.3% |

★「彼の気持ち」より「既読」の方が【2.7倍】多い。

```
領域 ： 既読のまま返事が来ん時間
敵   ： その時間に削られること（画面を開く、意味を探す、消耗する）
渡す ： 読み（彼が何を考えとるか）と、形（いつ動いて、いつ手を止めるか）
言わん： 保証と、慰め
```

★★よそは「彼の気持ちが分かる」を売っとる。椿は【待つ時間が、削られる時間でなくなる】を売る。
　 暦という現物を持っとるのは椿だけや。
★★★このコンセプトは発明やない。暦の納品文に、もうこの言葉が入っとった——
　　 「この紙は『待て』と言う紙やない。待つ時間に、形をつける紙や」。
　　 看板にしてへんかっただけや。

## 2. ★Threadsと同じ型は使えん（ここが設計の芯）

Mosseri（Instagram責任者・2025年1月）が挙げた順位の上位三つ：

> **watch time, likes and sends**（視聴時間・いいね・送信）

★★★コメントは上位三つに入ってへん。
　フォロー外の人には【送信】が強う、フォロー中の人には【いいね】が強い、とされとる。

```
Threads ： コメント（生まれ月をコメント → 1:1返信）で回る。実測 67本で513件
Instagram： 視聴時間・いいね・送信で回る。コメントは順位に効かん
```

★椿がThreadsで勝っとる仕掛けそのものが、Instagramのランキングには効かん。

### せやから、二層に分ける

| | 役割 | 効かせるもん |
|---|---|---|
| **伸ばす仕掛け** | 新しい人に届く | 視聴時間・送信 |
| **拾う仕掛け** | 届いた人を客にする | コメント → 自動DM |

★★コメントが順位に効かんことと、コメントで客を拾えんことは【別の話】や。
　 コメントはリーチを生まん。せやけど、生まれたリーチを拾う道具としては使える。
　 （Threadsの実測：コメント締め 1本7.7件／DM締め 0.1件／プロフ誘導 0.0件）

## 3. 導線

```
投稿（伸ばす仕掛けで作る）
  └ 締めは「彼の星座をコメントに置いてって」の一動作だけ
       ↓
コメント
  └ Metaの公式API（Private Replies）で自動DM。コメントから7日以内・1通まで
       ↓
DM
  └ その星座の短い一言 ＋ 既存のWeb無料診断のリンク（?src=ig_投稿ID）
       ↓
LINE（今の受け皿をそのまま）
```

★投稿本文からは診断にもDMにも送らん。場を移す手続きは、1対1の場でだけやる。
★★流入元は、合言葉やのうて診断ページのパラメータで測る。投稿単位まで取れる。
★★★非フォロワーへの自動DMは「リクエスト」フォルダに入る（通知が出ん場合もある）。
　　 公開返信で「DM送ったで。見当たらんかったらリクエスト見てな」の一言を添える。

## 4. アカウントの作り

### 名前
```
ユーザーネーム： @tsubaki_honne（Threadsと揃える）
名前欄　　　　： 椿｜既読スルー・音信不通・復縁
```
★名前欄はInstagramの検索に掛かる。客が実際に使う言葉を入れる（既読が40.6%）。

### プロフィール文（★値段は書かん）
```
既読のまま返事が来ん夜に、彼が何考えとるかを視る。

慰めへん。「必ず戻る」も言わん。
視えたことだけ、正直に書く。

一万字の鑑定書と、動く日を日付で決めた暦を渡しとる。
▼まずは無料で視る
```

★★★値段を外した分、信用は別のもんで作る。詐欺の型（無料・顔なし・DMで生年月日）と
　　 表面が似るんで、ここは手を抜けん。国民生活センターが注意喚起しとる形や。
　　 ・「慰めへん」「保証せん」＝詐欺の逆を、一行目に近いとこで言い切る
　　 ・現物を見せる（鑑定書の実物ページ。個人情報はぼかす）
　　 ・特商法の表記をリンクに置く
　　 ・AI生成の人物写真、作り物の鑑定風景は【絶対に出さん】。ペルソナが割れる

### リンク（5つまで置ける）
1. 無料診断（`?src=ig_bio`）
2. 個別鑑定書の申込
3. お客様の声（note）
4. 特定商取引法に基づく表記

### ハイライト（三つだけ。一度作って終い）
```
受け方 ／ 鑑定書の中身 ／ お客様の声
```
★毎日のストーリーズはやらん。フォロワーが少ないうちは見る人がおらん。

### 固定投稿（三本）
1. 椿が何をする人か（慰めへん宣言）
2. 鑑定書の中身（実物のページ）
3. お客様の声

## 5. 投稿の型

### 伸ばす仕掛け（★「友だちに送りたなるか」で作る）

| 型 | なんで効くか |
|---|---|
| 十二星座カルーセル | 自分の星座を探して14枚めくる＝**視聴時間**／「これあんたの彼やん」＝**送信** |
| 既読のまま◯日目にやってまうこと | あるある。**送信**されやすい |
| 彼の一言の翻訳（「忙しい」の意味 など） | 刺さると**送信**される |

★★★星座を残す理由は「Threadsで勝ったから」やない。そこは移せん。
　　 【視聴時間と送信を取れる形やから】に差し替えた。上位二つのシグナルに構造的に当たる。
　　 ★ただし日本のInstagramで機能しとる例は見つからんかった。これは理屈であって証拠やない。

### 拾う仕掛け
★全投稿の締めは同じ一動作：「彼の星座をコメントに置いてって」。
　投稿ごとに役割を分けん（Threadsで「拡散だけ狙う回」は廃止済み。同じ一動作で両方取れる）。

### カルーセルの穴（★作り直しが要る）
今の表紙は「十二星座ぜんぶ視た。あんたのとこだけ、めくって読み」。
★読者は自分の星座のページで止まる。牡羊座の人は2枚目で読み終わる。
　14枚目の入口まで届くんは、魚座の近くの人だけや。
★★行動の指示は【表紙・各ページの下帯・キャプションの冒頭】の三箇所に置く。

## 6. 最初の90日

### 測って決めること（★調べても分からんかったとこ）
Instagramは他人のファネルを見せん。ログイン画面で止まるし、閲覧代行サイトもCloudflareで弾かれる。
12アカウント特定したが、導線が見えたんは【ゼロ】やった。
★せやから、ここから先は調査やのうてテストで決める。

```
三週間・九本。同じ内容を、カルーセル版とリール版で出して比べる。
拾う動作は両方ともコメント一つに固定する。
見るんは三つだけ：送信数／平均視聴時間／コメント数
```

### 週に見る数字（三つだけ）
1. 1本あたりの星座コメント数
2. コメントからLINE登録までの率
3. IG経由の鑑定購入数

★フォロワー数といいね数は見ん。ただしフォロワーは別の意味で効く——
　自動DMは、フォロワーなら受信箱に、非フォロワーならリクエストフォルダに入る。
　★つまりフォロワー数はDMの到達率に直結する。追う数字やないが、無視もできん。

### 撤退線
単発売上は1登録あたり約250〜360円。週2時間（月9時間）使うなら、
★IG経由のLINE登録が月80人に届かん限り、同じ時間をLINEの中の転換に回した方が得や。
45日目は登録ペースで、90日目は購入件数で判定する。

## 7. 90日でやらんこと

1. **手で返すDM**。自動化が動くまで、DMの入口は開けん
2. **リールの量産**。`instagram_reels.md` の「1日1本・CapCut・トレンド音源」は、いったん捨てる
3. 毎日のストーリーズ
4. Instagram専用のネタ開発（素材はThreadsでリードが取れた型の上位だけ）
5. 無料のDM鑑定（@amano.tesou 型）
   ★あれが成り立つんは、手相には手の写真が要ってコメントに書けんからや。
   　椿の材料は星座と生年月日で、コメントと診断ページで足りる。形だけ真似たら摩擦が残るだけ
6. ハッシュタグの研究（今は1投稿5個まで。固定の5個で済ます）
7. 投稿の連発（最初の三週間は1日1本まで。★9/2の検問の教訓）
8. 広告、コラボ、二つ目のアカウント

## 8. ★Instagramは投資の四番目

転換率は、LINE登録1,648人に対して在籍13人で【0.79%】。
月詠みだけで50万円（84人）にするには、あと9,000人の登録が要る。月400人ペースで二年。

★★単価の道の方が近い。**潮暦20席が満席で39.6万円**、残りを月詠み18人で埋めて50万円。
　 合計【38人】や。84人やない。

★★★購入者116人のうち、Stripeリンクを見たんは【49人】だけ。見た人の34.7%が入っとる。
　　 残り67人は、月額の存在を知らんまま。

```
1. 解約率と、会員1人あたりの月の対応時間を測る（一週間）
2. 未案内の67人との接点を作り直し、潮暦20席を埋めにいく
3. Threadsの型配分を星座型に寄せ、本数は1日20〜24本・間隔1時間以上の内側に戻す
4. 上が回り始めてから、Instagramを「自動ミラー」として週2時間の枠で始める
```

★Instagramをやる理由は二つある。どっちも実測や。
　① Threadsが面として飽和しとる。コメントした人の新規率が 8月95% → 9月69% → 10月53%
　② 2025年7月から、プロアカウントの公開投稿はGoogleにも載る。
　　 Threadsは1〜2日で流れるが、カルーセルは保存と検索で何ヶ月も残る
★★逆に、分散の手段としては弱い。InstagramはThreadsと同じMetaで、アカウントも紐付く。
　 片方が止まれば両方止まり得る。本当の分散はLINEのリストとメールアドレスの取得や。

## 9. 先に確かめること

1. **椿のThreadsが、どのInstagramアカウントから作られとるか**。リポジトリに記録が無い。
   ★IG側で自動DMが違反と判定されたら、売上を全部作っとるThreadsまで止まり得る。
2. **自動DMはMetaの公式APIを使うもんに限る**（iDM 月3,980円／iステップ 月22,000円 など）。
   ★非公式ツールは凍結リスクの警告が出とる。
3. **潮暦の「相談制限なし」を、このまま売るか**。
   ★退会した2人は364通と473通を使うてから辞めとる。
   　使い放題の席に一番重い人が集まる形を、値段を上げて作り直してへんか。
