# 引き継ぎパッケージ｜SNS占い・相談ビジネスの自動化システム

このフォルダは、**このシステムを一から自分用に作り直して運用するための説明書**です。
プログラミングの知識がなくても、Claude Code に読ませながら進めれば構築できます。

---

## ■ Claude Code を使う人へ（最初にこれを読ませてください）

Claude Code を起動したら、まず次の一文を送ってください。

```
handoff/ フォルダの中身を全部読んで、私がこのシステムを自分用に作れるように、
最初から順番に案内してください。私はプログラミングが分かりません。
一度に一つずつ質問してください。
```

Claude Code はこのフォルダを読んで、あなたに質問しながら設定を作っていきます。
**分からないことは全部 Claude Code に聞いてください。**「これ何？」「なんでこれが要るの？」で構いません。

---

## ■ このシステムは何をするものか

SNS（Threads）で悩みを抱えた人を集め、LINE で無料相談に乗り、
その先で有料の鑑定書（PDF）と月額会員を売る、という商売を**ほぼ自動で回す**仕組みです。

```
Threads に投稿（Claudeで作ってスプレッドシートに仕込む→自動配信）
    ↓ 興味を持った人が
無料診断ページ（生年月日を入れるだけ）
    ↓ 結果と一緒に発行される番号を持って
LINE に登録
    ↓ 番号を送ると
無料の診断結果が自動で届く
    ↓ そこから AI が相談に乗る（自動）
    ↓ 相手が「どうしたらいい？」と言った瞬間
有料の鑑定書をおすすめ（自動）
    ↓ 買ってくれたら
あなたが鑑定書を作って渡す（AI が下書きを作る）
    ↓ 感想が返ってきたら
月額会員をおすすめ
```

**あなたが手を動かすのは「投稿を仕込むこと」「鑑定書を作って渡すこと」「買ってくれた人との会話」の3つだけ**です。
投稿の配信も、集客も、最初の相談も、システムが自動でやります。

なお **手動対応が必要になっても通知は来ません。**LINE公式アプリを1日2〜3回は自分で開いてください（`05` 参照）。

## ■ 大事な注意

**このシステムは人の悩みを扱います。**恋愛、家庭、お金、心の問題。
中には本当に追い詰まっている人が来ます。

- 「必ず良くなる」「絶対にうまくいく」と**保証してはいけません**
- 不安を過剰に煽って売ってはいけません
- 病気や健康について断定してはいけません
- 「死にたい」といった言葉が出たら、占いの話をやめて専門の相談窓口を案内してください
  （このシステムには自動でそうする仕組みが入っています。絶対に外さないでください）

このルールは `rules_*/04_avoid.md` に書かれています。**必ず引き継いでください。**
守らないと、アカウントが止まるだけでなく、人を傷つけます。
