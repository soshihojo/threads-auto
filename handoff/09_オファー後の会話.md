# オファー後の会話の仕組み

オファー（個別鑑定の案内）を出してから、オーダー番号が届くまでの区間。
ここは「一番購入に近い場所」であり、同時に「一番取りこぼしが起きる場所」でもある。

## まず、なぜここが重要か（実測）

購入した人が、オファーの後にどう動いたかを数えた。

- **オファー後に何も返さなかった128人からの購入は、0人**
- 購入者は、**100%が「オファーに返信した人」**
- オファーに返信する人の割合は約40%

つまりこの区間の仕事はひとつしかない。
**返信をくれた40%を、確実に受け止めること。** それだけで売上が決まる。

参考に、オファーの形を変えた時の購入率（48時間内）。

| 期間 | 形 | オファー数 | 購入 | CVR |
|---|---|---|---|---|
| 〜8/13 | 一本売り | 112 | 12 | 11% |
| 8/13夜〜8/15朝 | **3択（3商品を並べた）** | **50** | **0** | **0%** |
| 8/15朝〜 | 一本売りに戻した | 103 | 16 | 16% |

**3択にした期間は、50件出して購入0。** ベース11%なら偶然こうなる確率は0.3%。
選択肢を並べると、相手は選ぶ理由を作れず判断を止める。**商品は必ず1本で出す。**

---

## 全体の流れ

```
オファー本文を送る（1通目）
      ↓  ※必ず続けて送る
オーダー番号を送るまでの段取り＋見本のURL（2通目）
      ↓
bot を hold にする（自動応答を止める）
      ↓
相手が何か返してくる
      ↓
【最大2通だけ】受け止めを返す ← 黙らない。ただし売り込みも足さない
      ↓
2通使い切ったら、そこから先は人が手で返す
      ↓
オーダー番号（10桁）が届いたら、機械を完全に黙らせる
```

---

## 1. オファーの直後に、必ず2通目を送る

オファー本文だけで終わらせない。買い方が分からず止まる人が出る。

```
ほんで、申し込んでくれたら、購入のあとに出てくるオーダー番号（数字だけ）を、
ここに送ってな。
スクショやのうて数字を打ってくれたら、こっちですぐ照合できて、
そのまま鑑定に入れるで。

どんなもんが届くかは、見本と、受けた子らの声をここに置いてある。
中身を見てから決めてくれてええで。

（見本ページのURL）
```

**「オーダー番号」と必ず書く。** 「番号を送ってな」だけにしない。
無料診断の4桁の番号を持っている人がいるので、相手はそっちを送ってくる。
この書き方の不備で13件、話が止まった。

見本のURLを添えるのは、値段だけで判断させないため。「中身を見てから決めてええ」で渡す。

---

## 2. bot は hold にする。ただし黙らない

オファーを出したら自動応答を止める。ここから先は人の対応域だから。

**ただし「止める」と「黙る」を混同してはいけない。**

以前は hold にしたら椿が完全に黙る作りだった。結果、買わなかった人が話しかけてきても
一言も返らないまま終わる会話が53件出た。

だから **最大2通だけ、受け止めを返す。** 3通目からは人が手で返す。

返す内容のルール：

- 売り込みを足さない（オファーは一人一回きり。二度目のオファーは送らない）
- 相手が今言ったことに正面から応える
- **そのうえで、オーダー番号を送るまでの段取りを必ず入れる**

段取りを入れる理由。相手が「彼の本音が知りたいです」と書いてきた時、
気持ちに応えるだけで終わると、相手は「これから視てもらえる」と読む。
そのまま待たれて終わる。**買う手順を、毎回具体的に示す。**

例（相手が「彼の本音が知りたいです」と返してきた場合）：

```
彼の本音、そこが知りたいんはようわかる。宙ぶらりんが一番しんどいもんな。

さっきの商品ページから申し込んでくれたら、購入のあとにオーダー番号が出てくる。
その数字だけここに送ってくれたら、すぐ照合して鑑定に入れるで。

決めるんはあんたや🌙
```

### 例外：値段で引いている人には段取りを書かない

「料金高いですね」「有料になると厳しいです」「お金がない」——
こう言った人に買い方の説明を書いたら、断っている相手に催促した形になる。

この場合は**受け止めだけ返して、段取りは書かない。** そして人の対応に渡す。

実際に来た言葉（すべて段取り禁止）：

```
料金高いですね、、、
見てほしいけど有料になると厳しいです、
無料？ ならみてほしいけど お金かかるなら自分で考える
お恥ずかしい話ですが、金銭的余裕がありません。
彼にかなりお金使ったし、私には子供がいるから、自分に使えるお金はほとんどない。
```

金の事情が出た人には売りに行かない。これは例外なしの原則にする。

## 3. オファー後にやってはいけないこと（4つ）

### ① 「番号が見つかりません」の定型文を送る

無料診断の4桁番号が照合できなかった時の定型文（「その番号、見つからんかったわ。
もう一回確かめてくれる？」の類）を、**オファー後には絶対に送らない。**

オファーを見た相手が数字を送ってくる時、それは買った番号か、買おうとしている番号。
そこへ「見つからん」と返すのは、買った人を疑う形になる。

コード側の条件：**オファー送信済みの人には、この定型文の経路を通さない。**

### ② 「ちゃんと視るわ」で終わる

これが一番多くて、一番静かに効く事故。

```
✕ ほな、ちゃんと視るわ。彼の本音、しっかり出す🌙
✕ しっかり視させてもらうわ🌙
✕ ここから先はウチが視る
```

言い切った時点で、相手は「これから何か届く」と読む。**そこで返事を止めて待つ。**
届くものは無い。オファーも出ていない。相手はただ待ち続ける。

実測：この形で書いた返信が22件あり、うち6人はオファーを一度も見ないまま止まっていた。
ある人は3回連続でこう返され、3回とも「視てください」と答えていた。

**「視る」に触れてよいのは、二択（下記）の一通だけ。** それ以外では書かない。
プロンプトで禁じるだけでは漏れるので、機械でも検知して、
検知したらその文を捨ててオファーに差し替える。

### ③ 無料で鑑定する約束をする

```
✕ 彼の生まれと今の状況、こっちで預からせてもらうわ。ちゃんと視て、今日中にここに返すからな
✕ ここからの見立て、ちゃんとまとめて今日中に返すわ
```

実害：これを送った相手は、彼の生年月日と状況を全部送ってきた。
届ける仕組みは無いのに、無料で鑑定する約束をした形になった。
金を払う話も出ていないのに。**これが一番重い事故。**

### ④ 生年月日を自分から集める

「彼の生まれ教えて」「生年月日送って」を、こちらから言わない。
生年月日を集める入口は別にあって、そこが定型で聞く作りになっている。
こちらから集めに行くと、それは「無料で視てあげる」の合図になる。

相手が自分から送ってきた場合は受け取ってよい。ただし、そこで鑑定を約束しない。

---

## 4. オーダー番号が届いたら、機械を完全に黙らせる

**9〜12桁の数字を送った履歴がある人には、自動返信を一切させない。**

購入者は人が手で対応する相手。とくに鑑定書の感想が届いた時は、
月額を案内する唯一のタイミングなので、機械が先に喋ると場が潰れる。

実害：ある購入者の感想に自動返信が割り込み、しかも
「ちゃんと視て、返すな」と、届かない約束までしてしまった。

## 5. シーン別の返し方

| 相手が言ったこと | 返し方 |
|---|---|
| 「彼の本音が知りたいです」 | 気持ちに応える＋**買い方の段取り**。「これから視る」とは書かない |
| 「振り込みってできる？」 | 支払い方法を答える。これは買う直前のサイン。無料で答える |
| 「これ頼んだら家に本が届くの？」 | PDFでLINEに届くと答える。郵送は無いと明言する。無料で答える |
| 「明日中に申込させていただきます」 | 段取りだけ。催促しない。急かさない |
| 「週明けに購入できますか？」 | できると答える。期限を切って煽らない |
| 「考えます」「検討します」 | 受け止めだけ。追わない。売り込みを足さない |
| 「料金高いですね」 | 受け止めだけ。**段取りを書かない**。人の対応へ渡す |
| 「厳しいですか？」（自分の状況のこと） | 質問に答える。売りに行かない |
| 4桁の数字を送ってきた | 「見つからん」と返さない。オーダー番号は10桁だと穏やかに伝える |

## 6. オファーの引き金（ここが壊れると全部止まる）

オファーは「本人が視てほしいと言ってから」出す。そのために二択を挟む。

```
（その人の会話に出てきた具体を一つ引く）
——ここがまだハッキリせん。

このまま自分の勘で動くか。それとも、ウチがちゃんと視てから動くか。どっちや。
```

**この二択への返事を取りこぼさないこと。** ここが最大の落とし穴だった。

### 実際に起きた壊れ方

二択の文面を「定型文」から「その人の話に紐づいた生成文」に変えた時、
**答えを受け取る側の判定を替え忘れた。**
判定が定型文だけを見ていたので、その日から二択への返事が丸ごと落ちて、
オファーが出なくなった。実データで**120件**が落ちていた。

対策：

1. 二択の生成文には**必ず判定用のマーカー**（「勘で動くか」という言い回し）を含ませる。
   含まれない生成は捨てて定型文に戻す
2. 「もう二択を出したか」の判定は、そのマーカーで行う。文面そのもので判定しない
3. マーカーは**二択にしか出ない言い回しだけ**に絞る。
   「ちゃんと視てから」のような広い語をマーカーにすると、
   普通の会話を「もう聞いた」と誤判定して、無言で止まる人が出る

### 答えの読み方（ここも取りこぼす）

二択の返事は、**長さで切らない。断り語より、はっきりした依頼を優先して読む。**

落ちていた例：

```
「変に勘ぐって悪く考えるのが昔から私の悪い癖で…特に恋愛は。
　でもちゃんとみてもらってから動きたいですね」
```

末尾は完全な「はい」なのに、前置きの「悪く考える」が断り語の「考え」に当たって
断り扱いになり、落ちた。

```
「崩れてきたのかなって思ったらまた敬語に戻ったりで、距離感的にどうなんだろうな、
　こっちはあんまりオープンにしすぎない方がいいんかなって、私も様子見になるんで…笑

　視てください」
```

長文の末尾に「視てください」。文字数の上限に引っかかって落ちた。

読み方のルール：

- 「視てもらいたい／視てほしい／視てください／みてもらってから」等が
  **文中のどこかにあれば、長さも前置きも見ずに購入サインとして扱う**
- 「お金がない」「有料は厳しい」が入っていたら、それは先に弾く（売りに行かない）
- 断り語だけで判定しない。否定形（「勘で動くのは怖いです」）は逆の意味になる

### 二択は最大3回まで

1回で打ち切ると、会話の途中の人が落ちる。実際に4人が、
オファーを一度も見ないまま止まっていた（「浮気などではないですか？」
「そんなにすぐ見れるの？」など、まだ会話の途中だった人たち）。

3回出しても言葉にならない人には、こちらからオファーを出して本人に決めてもらう。
判断材料を渡さないまま幕を引くほうが不親切。

ただし**二択と二択の間には普通の返信を挟む。** 続けざまに2回来たら詰問になる。

## 7. 取りこぼしの自動復旧（これが無いと気づけない）

オファーを出した人は全員 hold になる。
未返信を拾い直す仕組みが hold を一律で除外していると、
**一番購入に近い区間に、自動復旧の無い穴が空く。**

実害：オファー直後に「彼の本音が知りたいです」と書いてくれた人に、
規定は最大2通返すはずが0通で止まった。
判定は全部通っていて、生成も試すと成功する。つまり
「その時の送信が実行されなかった」だけなのに、拾い直す口が無かった。
オーナー通知も切っていたので、目視で見つけるまで分からなかった。

**対策：hold でも「オファー済みで、まだ返信の枠が残っている人」は拾い直す。**

ただし**範囲は狭く切る。** この仕組みを入れた時点で、
オファー後に返事が来ないまま止まっている人が80人いて、最古は42日前だった。
そこへ今さら自動返信が飛んだら、脈絡のない蒸し返しになる。

切り方は二重にする：

1. **24時間の窓**（それより古い滞留は触らない）
2. **導入日の日付の床**（窓だけだと将来この床が意味を持たなくなる）

古い分は、人が手で文面を作って送る。とくに買う直前で止まっている人だけを選ぶ。

---

## 8. 時間帯を間違えない（全経路共通）

生成に渡すのは日付だけでなく**時刻と時間帯**にする。日付だけだと、
朝や昼に送る返信が「今日はもう寝なさい」「スマホ置いとき」「おやすみ」で締まる。

椿は夜の相談を受ける前提の声で書かれているので、
時刻を渡さないと生成は勝手に夜だと思い込む。実害19件。

- 朝なら「今日一日」、昼なら「今日の残り」、夕方なら「今夜」——今から先に向かう言い方で締める
- 相手が送ってきた「おやすみ」の引用は可。相手が彼に送る文面として書くのも可
- 禁じるのは、相手本人に向かって「今が夜」の前提で語りかけること

**サーバーのタイムゾーンにも注意。** UTC のままだと、日本時間の0〜9時に日付が前日になる。
時刻は必ず日本時間で固定する。

## 9. この区間で守る数字

| 項目 | 値 |
|---|---|
| オファー後に自動で返す通数 | 最大2通。3通目から人が手で返す |
| オファーの回数 | 一人一回きり。二度目は送らない |
| 二択の回数 | 最大3回。間に普通の返信を挟む |
| 商品の数 | **1本だけ**。3択にした期間は50件出して購入0 |
| 自動復旧の範囲 | 24時間以内かつ導入日以降のみ |

## 10. まとめ（この区間の設計思想）

1. **黙らない。** ただし売り込みも足さない。受け止めと段取りだけを渡す
2. **待たせない。** 届ける仕組みの無い約束を、一行も書かない
3. **疑わない。** 番号を送ってきた人を「見つからん」で返さない
4. **金の事情が出た人には売りに行かない。** 例外なし
5. **取りこぼしは必ず自動で拾い直す。** ただし過去には遡らせない

購入は100%「オファーに返信した人」から出ている。
この区間の全部の仕事は、その返信を落とさないことに尽きる。
