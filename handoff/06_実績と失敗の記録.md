# 06｜実績と失敗の記録

ここに書いてあることは、**全部実際にやって確かめた結果**です。
想像や一般論ではありません。同じ失敗を繰り返さないために読んでください。

---

## ■ 最重要｜投稿の勝敗は「締め方」で決まる

フックの良し悪しではありません。**最後の一行が全てです。**

### 死んだ締め方（リード0が確定）

**① 条件を並べる（多段CTA）**

> 「①この投稿にいいね ②フォロー ③固定投稿から無料診断（二人の生年月日を入れるだけ・30秒）」

- スベった投稿5本中5本がこの形でした
- **物語が最高でも死にます。**実際、勝ち投稿とほぼ同じ内容の投稿が、締めを多段にしただけでリード0になりました
- 手続きが増えるほど手が挙がりません

**② 予告して終わる**

> 「この続きは明日視るで。フォローして待っときな」

- これもスベり群に例外なく出ています
- 掴みがどれだけ強くても、予告で締めると手が挙がりません

この2つが**二大殺傷要因**です。

### 勝った締め方

**一段（動作ひとつ）で閉じる。**

> 「あんたの彼、何月生まれ？コメントで教えて」
> 「いいねとフォローして、DMに『無料鑑定』て送ってな」

その場で答えられる最軽量の動作にします。

## ■ 勝ちパターンの黄金比

```
生まれ月などの分岐  ＋  主客反転ストーリー  ＋  一段CTA
```

3つ揃うと、表示数が少なくてもリードが出ます。1つでも欠けると弱くなります。

### 主客反転ストーリーとは

```
動けなかった人がいた
  → 視たら「待つ縁やない、あんたから一言や」
  → 動いた
  → 翌日、返事が来た
  → 「当てたんやない、信じて動いたあんたが繋げたんや」
```

**最後の一文が肝です。**「占いが当てた」ではなく「あなたが動いたから」にすることで、
読んだ人が「自分にもできる」と思えます。これが最強の型として何度も再確認されています。

### 具体的な一手を必ず埋め込む

勝った投稿には必ず「あんたから一言でええ」のような**明快な行動指示**が物語の中に入っています。
抽象的な励ましでは手が挙がりません。読んだ人が動作をイメージできるかどうかです。

黄金比を当てたときだけです。表示数を狙った投稿は、表示されるだけで終わります。

## ■ 効かなかった切り口

### 読者を責める切り口

「あなたの癖」「あなたの重さ」を診断する形は死にました。
自分ごと化されず、むしろ離れます。

分岐が跳ねるのは「**相手の未練・本音**」を明かす文脈のときだけです。

### 自分語りだけで終わる投稿

キャラの実体験は共感装置として効きます。
ただし、締めが事務的だと台無しになります。温度を作ったら、そのまま一段CTAで閉じてください。

### 選別フレーズの過信

「本気で知りたい子だけ」という選別は効きます。
ただし**多段CTAに繋げると死にます。**選別は一段CTAとセットでのみ機能します。

## ■ 販売について確かめたこと

### 一斉オファーは0成約

テンプレートの一斉オファーを13件送って、**成約ゼロ**。反応も悪化しました。

売れるのは「1対1で自分だけを見てもらっている」と感じている時だけです。
**この感覚こそが商品価値**です。一斉配信はそれを壊します。

### 安ければ売れるわけではない

199円のお試し商品（一問だけ答える）を作りましたが、
**2,980円の本商品より売れませんでした。**

安さは信用を作りません。「ちゃんと視てもらえる」という期待のほうが、購入を決めます。
現在は199円の商品は廃止し、2,980円の1本に絞っています。

### 買う瞬間は決まっている

相手から次の言葉が出た瞬間です。

> 「どうしたらいい？」「いつ動けば？」「いつ送ったら？」「なんて送れば？」「料金は？」

これが出るまでは、共感 → 洞察 → 質問で会話を深めるだけです。
出た瞬間に、迷わせずに購入前提の段取りで返します。

### 無料の線引きが収益を決める

| 無料で渡してよい | 有料に取っておく |
|---|---|
| 相手の性質・今の状態の読み | いつ・何を・どう動くか |
| 何が起きているかの解説 | 送る文面そのもの |
| | 時期 |

全部渡すと売れません。何も渡さないと信用されません。

## ■ アカウント運用で起きた事故

### Threads の DM 大量返信で BAN された

これが**この設計の出発点**です。
だから今は、Threads 側では返信も DM もせず、無料診断ページに入口を集約しています。

DM を使う場合も、1人1通・連投なし・間隔をあける、を厳守してください。

### 有料客に「画像は見ません」と自動返信した

無料相談者向けの断り文が、購入者にも飛んでいました。
証拠のスクリーンショットを送ってくれた人に、断りを返してしまった形です。

**購入報告は「オーダー番号を数字で送って」と案内する**のが正解です。

### スプレッドシートの列が1つズレて、自動投稿が2日間止まった

2026-08-01。コードが期待する列がシートから失われていて、日付を別の列として読んでいました。
条件に合う行が0件になり、**エラーも警告も出ないまま、投稿だけが静かに止まりました。**

気づいたのは「最近投稿されていないな」と人間が思ったときです。
シートを手で編集する運用にする以上、この事故は必ず起きます。列構成は絶対に変えないでください。

### 同じ安全装置が2箇所に書かれ、片方にしか無かった

占いの専門用語（宿の名前）が本文に漏れないよう、最後に日常語へ置き換える処理があります。
これが**LINEの自動返信にしか入っておらず**、月額会員への返信・無料診断・有料鑑定書には入っていませんでした。

結果、有料会員への返信に「觜宿の彼はな、」と**宿名がそのまま出て届いていました。**
プロンプトで「専門用語を書くな」と指示していても、AIは時々漏らします。**最後に機械的に置き換える処理が要ります。**

2026-08-02に、置き換え処理を1箇所に統一して、生成する全経路（無料診断・自動返信・オファー・
会員相談・月額鑑定・有料鑑定書）を必ずそこに通すよう直しました。

**教訓**：同じ安全装置を2箇所に書くと、必ず片方だけ古くなります。1箇所に置いて全部から呼んでください。

### 削除作業で、必要な定義まで巻き添えで消した

2026-08-02。使っていない機能を消したとき、**その直後にあった別の定義まで一緒に消してしまい**、
LINEの無料診断が全ユーザーで停止しました。ファネルの入口が止まった状態です。

厄介なのは、**プログラムの起動時にはエラーが出なかった**ことです。実際にお客さんが番号を送って、
初めて落ちました。気づいたのは「返信が来ていない」と人間が気づいたときでした。

**教訓**：コードを消すときは、消す範囲の中身を1行ずつ読んでください。「ここからここまで」で
機械的に切り取ると、関係ないものを巻き込みます。消したあとは起動確認だけでなく、
**実際に機能を動かして**確かめてください。

### 同じ人にオファーが2回届いた

タイミングの重なりで二重送信が起きました。
現在は防止処理が入っていますが、送信前に履歴を確認する習慣は持っておいてください。

## ■ 相談者が実際に使う言葉（フックの材料）

累計354人の相談ログから抽出したものの一部です。
**この解像度で書くと「私のことだ」と思わせられます。**

- 「用事がある限りの時だけ連絡する」（＝用事を作ってでも繋がりたい、という自覚なき本音）
- 「私から送らないと3週間ぐらいは平気で連絡ない」
- 「私が折れたら本当に切れそうで怖い」
- 「こっちが勝手に考えてるだけで、あっちからしたら知らない話だからね」（一人相撲の自覚）
- 「ずっとみてもうてた」（相手のSNSを覗いてしまう告白）
- 「聞いたら関係が壊れるかもしれないと思うと聞けません」
- 「ご飯も食べれない、味がしない」「元気なふりするのもしんどい」

**自分で考えた言葉より、実際の相談者の言葉のほうが100倍刺さります。**
運用が始まったら、届いた言葉を必ず記録してください。自動で集める仕組みも入っています。

### 相談の内訳（多い順）

1. 音信不通・既読スルー（最多）
2. 復縁したい
3. 急に冷められた・突然ブロックされた
4. 片思いで進展しない
5. 既婚・婚外恋愛
6. 占いジプシー（他の占いで傷ついた人）
7. 心身の限界

**6番は特に大事です。**「不安を煽られてカードで決済した」「借金してまで注ぎ込んだ」という人が来ます。
そういう人を、また同じ目に遭わせないでください。

## ■ 最後に｜このビジネスで一番大事なこと

売上の話ではありません。

来る人は、**友達にも家族にも言えないこと**を書いてきます。
夜中に一人で、誰にも見せられない文章を打っています。

その人にとって、あなたのアカウントは「唯一言える場所」になります。

だから：
- 慰めの嘘を書かない
- 保証しない
- 不安で釣らない
- 本当に危ない人には、売らずに専門機関を案内する

**この線を守った上でしか、この商売は続きません。**
守らなければ、短期的に売れても、必ず終わります。人を傷つけた分だけ、跳ね返ってきます。
