# 03｜構築手順（ゼロから動かすまで）

**所要時間の目安：合計15〜20時間**（待ち時間を含む。数日に分けてください）

うち **4〜6時間が STEP 9（診断ページの作り直し）** です。ここが一番重い工程です。

つまずいたら、その STEP の番号とエラーメッセージを Claude Code に貼ってください。

---

```

STEP 3  データの保存場所を作る      30分  ← 詳細は DEPLOY.md

STEP 11 LINE ボットを繋ぐ          60分  ← 詳細は DEPLOY_LINE.md
```

**STEP 5 まで終われば、文章の生成は試せます。**まずそこを目指してください。

> **STEP 9 が想像以上に重いので、先に心づもりを。**
> 診断ページは、前の持ち主のキャラと世界観で丸ごと作り込まれています。
> 名前を差し替えるだけでは済まず、**診断の中身そのものを全部書き直す**ことになります。
> ここを飛ばすと、あなたのアカウントなのに前の持ち主の世界観のページに人を送ることになります。

## STEP 1｜パソコンの準備

### 1-1. 必要なソフトを入れる

- **Python 3.10以上** … https://www.python.org/downloads/
- **Git** … Mac なら最初から入っています。Windows は https://git-scm.com/
- **Google Chrome** … 鑑定書を PDF にするのに使います
- **Claude Code** … これが一番の助っ人です

### 1-2. プログラム一式を手元に置く

引き継いだフォルダをそのままコピーするか、GitHub から取得します。

### 1-3. 動く準備をする

ターミナル（Windows なら PowerShell）で、フォルダの中に入って実行します。

```bash
python -m venv .venv
source .venv/bin/activate      # Windows は .venv\Scripts\activate
pip install -r requirements.txt
```

エラーが出たら、そのまま Claude Code に貼ってください。

## STEP 2｜AI（Claude）のキーを取る

1. https://console.anthropic.com/ に登録
2. クレジットカードを登録して、少額（5〜10ドル程度）をチャージ
3. 「API Keys」から新しいキーを作成
4. `sk-ant-...` で始まる文字列をコピーして、**どこかに安全に保存**

> **このキーは絶対に人に見せないでください。**SNS に貼る、GitHub に上げる、は厳禁です。
> 漏れると他人にあなたのお金で使われます。

### 設定ファイルを作る

フォルダの中の `.env.example` をコピーして `.env` という名前にします。
その中の `ANTHROPIC_API_KEY=` の右側に、さっきのキーを貼ります。

```
ANTHROPIC_API_KEY=sk-ant-ここに貼る
```

`.env` は**絶対に GitHub に上げてはいけません**（設定済みなので、そのまま使えば大丈夫です）。

## STEP 9｜診断ページを自分用に作り直す（★4〜6時間）

**ここが一番の大仕事です。**無料診断ページは集客の入口そのもので、しかも前の持ち主の
キャラ・テーマで全部書かれています。中身を丸ごと入れ替えてください。

対象は `src/web_diag.py`（全383行）の1ファイルだけです。
**仕組み（判定 → 番号発行 → LINE連携）はそのまま使えます。**書き換えるのは中身と見た目です。

### 9-1. 二人のタイプ（6種）を作り直す

`EN_TYPES` にある6種類です。相手との関係性を6タイプに分ける部分で、
**診断結果としてその場に表示される、一番読まれる文章**です。

1件ぶんの形はこうなっています。

```python
{
    "name": "写し鏡の縁",           # タイプ名
    "yomi": "うつしかがみのえん",    # 読みがな
    "catch": "似すぎるほど似た二人",  # 一行キャッチ
    "desc": "あんたと彼は、根っこの性質が…",  # 説明文（120〜160字）
}
```

書き方のコツ：
- **説明文の後半に必ず「引っかかり」を残す。**「今の膠着は、たぶんそれや」のように、
  当てて終わらせず「だから今こうなってる」まで書くと、続きが知りたくなります
- キャラの口調で書く。丁寧な解説文にすると一気に他人事になります
- 6種すべてに優劣をつけない。どれが出ても「自分のことだ」と思える書き方にする

### 9-2. 単体のタイプ（12種）を作り直す

`LOVE_TYPES` にある12種類です。**本人の生年月日だけで決まるタイプ**で、
**シェアされる（拡散する）のはこちら**です。ここの出来が流入量を左右します。

```python
"bannin": {
    "name": "慎重すぎる番人", "yomi": "しんちょうすぎるばんにん",
    "catch": "好きでも、動けん",
    "line": "石橋叩きすぎて渡らへんタイプ。慎重なんはええけど、それで何回チャンス見逃してきた？"
},
```

**ここが一番の腕の見せどころです。**思わずスクショして人に見せたくなる名前にしてください。

- 名前は**short で刺さるもの**。「慎重すぎる番人」「孤高の女王」「かまってちゃん」のように、
  一目で自分か他人か分かる語感にする
- `line` は**図星を突いて、少し笑える**くらいがちょうどいい。責める方向に行くと共有されません
- 悩みそのものは出さない。**人に見せられる内容**にする（だから拡散します）

### 9-3. 判定の割り当てを作る

`_LOVE_ASSIGN` が「占いの体系 → 12タイプ」の対応表です。
あなたが使う体系に合わせて、全パターンを12タイプに割り振ってください。
偏りが出ないよう、なるべく均等に散らします。

### 9-4. 見た目とコピーを差し替える

`PAGE_HTML`（約213行）の中にあります。以下は必ず変わります。

| 場所 | 現状の例 | 何にするか |
|---|---|---|
| `<title>` | 椿の縁視｜彼の本音、視たろか | 診断名とキャッチ |
| `<h1>` | 椿の縁視 | 診断名 |
| シェアバッジのタグ | #椿の縁視 | あなたのハッシュタグ |
| バッジの署名 | —— 椿 | キャラ名 |
| フッター | 椿｜彼の本音しか視ん | キャラ名と一言 |
| シェア文（JavaScript） | 「私の恋愛タイプ、【】やった…当たりすぎて笑う😇」 | あなたの言葉で |
| 配色・フォント | 和風・紫基調 | キャラの世界観に合わせる |
| 入力欄のラベル・ボタン | 「彼の生年月日」等 | テーマに合わせる |

### 9-5. Claude Code にやらせる

**この作業は自分で書かなくて大丈夫です。**02のワークシートを渡して、こう頼んでください。

```
02で決めた内容（貼る）をもとに、src/web_diag.py を私のアカウント用に作り直してください。
・EN_TYPES の6種、LOVE_TYPES の12種を、私のテーマとキャラの口調で全部書き直す
・_LOVE_ASSIGN の割り当てを作る
・PAGE_HTML の文言と配色を私の世界観に変える
・仕組み（番号発行・LINE連携）は変えないでください
```

### 9-6. 確認する

書き換えたら、必ず自分の目で見てください。

```bash
./.venv/bin/python -c "
from src import web_diag
print(web_diag.en_type('1990-01-01','1988-05-05'))
print(web_diag.love_type('1990-01-01'))
"
```

そのあとローカルでページを開いて、**実際に自分の生年月日を入れてみてください。**
「これなら人に見せたくなるか」を基準に判断します。ならなければ書き直しです。

## STEP 10｜診断ページを公開する

無料診断ページ（生年月日を入れると結果と番号が出るページ）を公開します。

1. Render（https://render.com）に GitHub アカウントで登録
2. New → Web Service → リポジトリを選択
3. 設定：
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn line_app:app --host 0.0.0.0 --port $PORT`
   - Instance Type: **Free**
4. 環境変数を登録（`DEPLOY_LINE.md` の表を参照）
5. 発行された URL の末尾に `/shindan` を付けたものが診断ページです

この URL を `config.yaml` の `web_diag_url` に設定し、Threads の固定投稿に載せます。

> STEP 9 を飛ばしてここに来た人へ。**先に中身を作り直してください。**
> 前の持ち主の世界観のまま公開すると、あなたのアカウントから来た人が混乱します。

## STEP 11｜LINE ボットを繋ぐ

**→ `DEPLOY_LINE.md` をそのまま実行してください。**

やることの要約：
1. LINE 公式アカウントを作る
2. Messaging API を有効にする
3. Channel secret とアクセストークンを取得
4. **応答メッセージを「オフ」**にする（二重返信になるため）
5. あいさつメッセージを設定する（`funnel/line_step_7days.md` の Day0 を参考に）
6. Webhook URL に `https://＜RenderのURL＞/webhook` を設定
7. UptimeRobot（無料）で5分ごとに叩いて、サーバーが寝ないようにする

自分の LINE からメッセージを送って、返事が来れば完成です。
