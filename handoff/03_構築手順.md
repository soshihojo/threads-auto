**所要時間の目安：合計3〜5時間**（待ち時間を含む。1日で終わらせなくてよい）

つまずいたら、その STEP の番号とエラーメッセージを Claude Code に貼ってください。

## STEP 1｜パソコンの準備

### 1-1. 必要なソフトを入れる

- **Python 3.10以上** … https://www.python.org/downloads/
- **Git** … Mac なら最初から入っています。Windows は https://git-scm.com/
- **Google Chrome** … 鑑定書を PDF にするのに使います
- **Claude Code** … これが一番の助っ人です

### 1-2. プログラム一式を手元に置く

引き継いだフォルダをそのままコピーするか、GitHub から取得します。

### 1-3. 動く準備をする

ターミナル（Windows なら PowerShell）で、フォルダの中に入って実行します。

```bash
python -m venv .venv
source .venv/bin/activate      # Windows は .venv\Scripts\activate
pip install -r requirements.txt
```

エラーが出たら、そのまま Claude Code に貼ってください。

## STEP 2｜AI（Claude）のキーを取る

1. https://console.anthropic.com/ に登録
2. クレジットカードを登録して、少額（5〜10ドル程度）をチャージ
3. 「API Keys」から新しいキーを作成
4. `sk-ant-...` で始まる文字列をコピーして、**どこかに安全に保存**

> **このキーは絶対に人に見せないでください。**SNS に貼る、GitHub に上げる、は厳禁です。
> 漏れると他人にあなたのお金で使われます。

### 設定ファイルを作る

フォルダの中の `.env.example` をコピーして `.env` という名前にします。
その中の `ANTHROPIC_API_KEY=` の右側に、さっきのキーを貼ります。

```
ANTHROPIC_API_KEY=sk-ant-ここに貼る
```

`.env` は**絶対に GitHub に上げてはいけません**（設定済みなので、そのまま使えば大丈夫です）。

## STEP 3｜データの保存場所を作る（Google スプレッドシート）

**→ `DEPLOY.md` の STEP 1 をそのまま実行してください。**

やることの要約：
1. Google Cloud でサービスアカウントを作る（無料）
2. Google Sheets API を有効化する
3. 鍵（JSONファイル）をダウンロードする
4. スプレッドシートを1枚作って、サービスアカウントのメールアドレスに**編集者**で共有する
5. `.env` に3行追記する

確認コマンド：

```bash
python -m src.main check-store
```

`✅ 読み書きOK` が出れば成功です。スプレッドシートにタブが自動で作られます。

> **なぜスプレッドシートなのか**：管理画面と自動投稿の仕組みが、同じデータを見る必要があるからです。
> パソコンの中だけに保存すると、ネット上の仕組みから読めません。

## STEP 5｜ローカルで動作確認

### 投稿が作れるか試す

```bash
python -m src.main post --dry-run
```

投稿文が表示されれば成功です（`--dry-run` なので実際には投稿されません）。

**必ず何本か出して読んでください。**キャラがブレていないか、変な言葉が混ざっていないかを確認します。
おかしければ STEP 4 に戻って設定を直します。

### 管理画面を開く

```bash
streamlit run app.py
```

ブラウザが開いて画面が出れば成功です。

## STEP 6｜Threads と繋ぐ

**→ `README.md` の「セットアップ」をそのまま実行してください。**

やることの要約：
1. Meta（Facebook）の開発者登録
2. Threads API のアプリを作る
3. 権限を有効にする（`threads_basic` `threads_content_publish` など）
4. 自分のアカウントを「Threads testers」に追加して承認
5. トークンを発行して、**長期トークン（60日）に交換**
6. `.env` に貼る

> ここが一番の関門です。画面が英語で分かりにくいので、
> **詰まったら画面のスクリーンショットを Claude Code に見せてください。**

長期トークンは自動更新される仕組みが入っているので、一度通れば以後は気にしなくて大丈夫です。

## STEP 7｜管理画面をネットに置く

**→ `DEPLOY.md` の STEP 2〜3 をそのまま実行してください。**

## STEP 8｜自動投稿を有効にする

**→ `DEPLOY.md` の STEP 4 をそのまま実行してください。**

GitHub Actions に秘密情報を登録すると、以下が自動で回ります。

| 仕組み | 頻度 | 中身 |
|---|---|---|
| `threads-scheduler` | 15分ごと | 予約時刻が来た投稿を配信 |
| `threads-poll` | 2時間ごと | コメントを取得してリードを検知 |
| `threads-learn` | 3日ごと | 反応を分析してルールを自動更新 |

> 投稿を自動生成するワークフローは**削除しました**（2026-08-01）。
> 投稿は Claude のプロジェクトで作り、スプレッドシートに直接書き込む運用です。
> 詳しくは `05_運用マニュアル.md` の「投稿を仕込む」を読んでください。

## STEP 9｜診断ページを公開する

無料診断ページ（生年月日を入れると結果と番号が出るページ）を公開します。

1. Render（https://render.com）に GitHub アカウントで登録
2. New → Web Service → リポジトリを選択
3. 設定：
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn line_app:app --host 0.0.0.0 --port $PORT`
   - Instance Type: **Free**
4. 環境変数を登録（`DEPLOY_LINE.md` の表を参照）
5. 発行された URL の末尾に `/shindan` を付けたものが診断ページです

この URL を `config.yaml` の `web_diag_url` に設定し、Threads の固定投稿に載せます。

## STEP 10｜LINE ボットを繋ぐ

**→ `DEPLOY_LINE.md` をそのまま実行してください。**

やることの要約：
1. LINE 公式アカウントを作る
2. Messaging API を有効にする
3. Channel secret とアクセストークンを取得
4. **応答メッセージを「オフ」**にする（二重返信になるため）
5. あいさつメッセージを設定する（`funnel/line_step_7days.md` の Day0 を参考に）
6. Webhook URL に `https://＜RenderのURL＞/webhook` を設定
7. UptimeRobot（無料）で5分ごとに叩いて、サーバーが寝ないようにする

自分の LINE からメッセージを送って、返事が来れば完成です。

### 最初にやること

**いきなり売ろうとしないでください。**

まず投稿を2週間ほど続けて、無料相談を受けてください。
どんな人が来て、何に困っているのかが分かってから、初めて売り方を調整します。

その間に来た相談の言葉は宝です。**そのままの言い回しを投稿に使う**と、一気に刺さるようになります。
