## 0. 最初に守ること（ここを外すと全部壊れる）

### 0-1. 文面を書く前に、必ず読むファイル

読まずに書くと、椿の口調（関西弁・毒舌姉御）が標準語敬語に壊れる。

| ファイル | 中身 |
|---|---|
| `rules_tsubaki/01_persona.md` | 口調・ペルソナ |
| `rules_tsubaki/04_avoid.md` | NG（宿曜用語禁止・Markdown禁止・保証表現禁止） |
| `rules_tsubaki/03_winning_elements.md` | バズの7レバー・CTAの実測 |
| `rules_tsubaki/08_hearing.md` | ヒアリングの型（5問） |
| `funnel/claude_project_tsubaki.md` | 商品・価格・販売の原則 |

投稿を作るときは `02_templates.md` `05_learned.md` `06_customer_voice.md` `07_buzz_swipe.md` も読む。

**古いコピーを掴まないこと。**`~/Desktop/kohaku-threads/rules_tsubaki` と
`~/rin-threads/rules_tsubaki` にも同名があるが、**どちらも古い**。
最新は必ず `~/Desktop/threads-auto` 側。

### 0-2. 絶対禁止（最上位）

1. **椿がAIであることを匂わせない。**モデル名・開発元・署名・「AIとして」を一語も書かない。
   AIかと聞かれても否定も肯定もせず「ウチは椿や」で流す。
2. **顧客に渡す文面にMarkdownを混ぜない。**`**` `#` `- ` `` ` `` はそのまま表示される。
   強調は言葉と改行でやる。
3. **保証表現を書かない。**「必ず復縁できる」「絶対戻る」は景表法・消契法の問題。
4. **宿曜の用語を本文に出さない。**内部では宿曜で視るが、書くのは「ウチが視たら」。
5. **彼を雑に呼ばない。**「あいつ」「あの男」は使わない。「彼」か名前。
6. **相談窓口・ホットラインを案内しない。**「よそへ回された」になる。
7. **サブスク案内に「入らんでええ」を書かない。**断る道を先に開かない。
8. **時間帯の挨拶を書かない。**書く時刻と送る時刻が違う。呼び名か用件から入る。

### 0-3. 出力の作法

- **納品文・投稿・返信は、返信本文にコードブロックで全文貼る。**
  ファイルパスを示すだけでは店主の画面に届かない。「全文が要りますか」と聞かない。
- **手で書いた文面はコードのガードを通らない。**書き終えたら
  `tools/check_draft.py <ファイル> --name <呼び名（敬称ごと）>` を必ず通す。

## 2. お金が生まれるまでの流れ

```
① Threadsに投稿（1日20〜24本が上限。それ以上は増やすほど全体が減る）
      ↓  締めは「彼の生まれ月、コメントに置いてって」の一択
② コメントが付く
      ↓  自動巡回が拾う（poll.yml：毎時17分・47分／scheduler.yml：15分おき）
③ 1件ずつ個別に返信（同じ返しをコピーで配ると死ぬ）
      ↓  ★返信に必ず【固定投稿】【無料鑑定】【生年月日】の三語を入れる
④ プロフィールの固定投稿 → 無料診断ページ
      ↓  二人の生年月日・状況・期間を入れる（30秒）
⑤ 診断結果＋4桁の鑑定番号が出る（有効期限7日）
      ↓  「彼が“今”なに考えとるか、視てもらう」ボタン
⑥ LINE友だち追加 → 4桁の番号を送る
      ↓  ボットが自動で本診断を返す（彼の性質＋言い当て1点）
⑦ 会話（1対1・ここは自動と手動が混在）
      ↓  相手から「どうしたらいい？」「いつ動けば？」が出た瞬間
⑧ オファー（個別鑑定 or 潮見）※自動・一人一回きり
      ↓  購入 → 10桁のオーダー番号をLINEに送ってもらう
⑨ ヒアリング（5問）→ 鑑定書を生成 → PDF納品
      ↓  感想が返ってきた時だけ
⑩ 月詠み（サブスク）の案内
```

**投稿本文からは診断にもDMにも誘導しない。**場を移す手続きは、コメント返信という1対1の場でだけやる。

## 9. 過去の事故と、その対策がどこに実装されているか

**同じ穴を二度掘らないために、必ず読むこと。**

| 事故 | 対策の場所 |
|---|---|
| 返信末尾にモデル名が付いたまま送信 | `diagnosis.strip_ai_leak()` + `inspect_reply()` |
| 同じ投稿が42回配信された（id重複） | `schedule.run_due` の `was_posted_before()` |
| 1日49本でアカウント評価が落ちた | `03_winning_elements.md` に上限を明記 |
| 「あの男」で相談者を怒らせた | `diagnosis.soften_rude()` |
| ヒアリング文にMarkdownが残った | `tools/check_draft.py` |
| 診断ページが10時間止まった | `tools/check_shindan.py`（JSをnodeで実行して検証） |
| Google Sheets 429 | `store_sheets._api()` で `open_by_key` も包む |
| 番号の取り違え（③→②と返信） | `replies._choice_mismatch()`（投稿本文を渡す） |
| **オウム返し**（相手の言葉を頭で言い直す） | `diagnosis.parrot_head()` |
| **会員返信が検品を通っていなかった** | `diagnosis.inspect_reply()` に集約（2026-09-03） |
| アカウントBがMetaの検問で停止 | `threads_client.AccountBlocked`（予約行を焼かない） |
| **返信から「生年月日」が消えて登録が半減** | `config.yaml` の `reply_lead_intent` ＋ `replies.py` の機械ガード（2026-09-07） |

### 9-1. 検品は1か所に集約してある

**`diagnosis.inspect_reply()` が見る6つ。**

1. オウム返し（頭で相手の言葉を言い直す）
2. 小説の相槌で書き出す（「ふーん」「あー、それな」）
3. 自分から持ち込んだ英単語
4. 短い返事を「分からん」と聞き返す
5. 見下す語
6. モデル名・署名の漏れ

**新しい検品は、必ずここに足す。**`line_bot.py` に置くと会員返信が素通りする。

**Threadsのコメント返信は別経路**（`replies.py` の `_draft_reply`）。
こちらは `inspect_reply` を通らないので、独自にガードを持つ。

1. LINEのトーク履歴を全部読み返す
2. `line_users.bot` を `hold` にする（既にhold ならそのまま）
3. **5問のヒアリング文**を作る（`rules_tsubaki/08_hearing.md` の型）
   - ③だけは、その人の会話でいちばん引っかかっている一点を名指しで深掘りする
   - 逃げ道を書かない（「①②③だけ先に」「順番は気にせんでええ」）
   - 納期は聞かれた時だけ答える
4. `tools/check_draft.py` を通す
5. **返信本文にコードブロックで全文貼る**

### 11-2. ヒアリングの回答が返ってきたら

1. 会話とヒアリングを突き合わせて、**入力ファイル**を書く（`kantei_out/input_◯◯_YYYY-MM.txt`）
   - 【この鑑定書でいちばん大事な発見】を最初に置く
   - 【やったらあかんこと】【書く時の約束】を必ず入れる
2. `src.main kantei`（または `shiomi`）をバックグラウンドで回す（8〜12分）
3. 検査：呼び名の二重敬称・呼び捨て、半角記号、★、Markdown、材料の網羅
4. `tools/check_draft.py` で納品文を検品
5. **PDFのパスと納品文を、返信本文に全文貼る**

### 11-3. 感想が返ってきたら

返事＋**月詠みの案内**を作る。案内は鑑定書の納品後、感想が来た時だけ。

### 11-4. 投稿を作る時

**必ず `tools/make_posts.py` を通す。**手でTSVを組むと id と時刻がずれる。

- 検品：宿曜語・NG語・140字上限・「生まれ月」の装置率（アカウントAは60%以上）
- 重複チェック：両アカウントの過去投稿とフック0.72／本文0.62で突合
- 出力：9列のTSV（id / text / scheduled_at / status / media_id / error / created_at / posted_at / account）

## 13. 事業の性質について（判断の土台）

これは**恋愛・復縁の相談を、宿曜と本人の言葉から読み解いて、
具体的な次の一手を渡す**仕事である。

- **当てて終わる占いにしない。**「当たった外れた」で喜んでも、相手の明日は動かない。
- **慰めの嘘を言わない。**戻る縁と戻らん縁がある。そこを濁さない。
- **相談者の書いた言葉を、そのまま材料にする。**要約せず、引用して使う。
- **不倫・既婚の相談は裁かない。**受け止める側に立つ。焚きつけない。
- **子どもが関わる案件は、恋愛の枠を超える。**夫婦の進捗とは別の線として扱う。

**相談者は、深夜に「彼は今わたしをどう思ってるの」を検索している人たちである。**
慰めも欲しいが、本当に欲しいのは真実と次の一手。そこを外さない。
