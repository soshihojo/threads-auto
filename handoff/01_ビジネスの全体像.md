# 01｜ビジネスの全体像

## ■ どこでお金が生まれるか

商品は**2つだけ**です。増やさないでください。増やすと、どれを売るか迷って結局売れません。

| 商品 | 価格の例 | 中身 | いつ売るか |
|---|---|---|---|
| **個別鑑定書** | 2,980円（通常価格9,980円からの割引という見せ方） | その人専用の PDF。全8章・約10,000〜12,000字 | LINE で相談中、相手が「どうしたらいい？」と言った瞬間 |
| **月額会員** | 月2,980円 | 毎月ミニ鑑定書 PDF ＋ LINE 相談し放題 | 鑑定書を渡して、感想が返ってきた時だけ |

※価格はあなたが決めます（02 参照）。ここに書いてあるのは実際に運用している一例です。

### 割引の見せ方について

「通常9,980円 → 縁ができたあなただけ2,980円」という見せ方をしています。
これは**嘘の元値をつけてはいけません。**販売ページの正規価格を実際に9,980円に設定したうえで、
割引価格で案内する形にしてください。景品表示法（二重価格表示）の問題になります。

## ■ お客さんが来てから買うまでの道のり

```
① Threads の投稿を見る
      ↓  「自分のことだ」と思う
② プロフィールの固定投稿から無料診断ページへ
      ↓  自分と相手の生年月日を入れる（30秒）
③ 診断結果 ＋ 4桁の番号 が出る
      ↓
④ LINE に登録して番号を送る
      ↓  自動で本格的な無料診断が届く
⑤ 「当たってる」と返信が来る
      ↓  AI が相談に乗る（最大10通まで無料）
⑥ 「どうしたらいい？」「いつ動けばいい？」が出る ＝ 買う瞬間
      ↓  AI が自動で鑑定書をおすすめ
⑦ 購入 → 詳しい状況を送ってもらう
      ↓  あなたが鑑定書を作る
⑧ PDF を渡す
      ↓  感想が返ってくる
⑨ 月額会員をおすすめ
```

### この道のりで一番大事なこと

**⑥まで絶対に売らないこと。**

過去に、テンプレートの一斉オファーを13件送って**成約ゼロ**でした。反応もむしろ悪化しました。
売れるのは「1対1で自分だけを見てもらっている」と感じている時だけです。

だから AI は⑤の間、**売り込みを一切しません。**共感して、洞察をひとつ渡して、質問を返すだけです。
相手のほうから「どうしたらいい？」が出た瞬間に、初めて商品の話をします。

## ■ 無料でどこまで渡すか（ここが収益の分かれ目）

| 渡してよい | 渡してはいけない |
|---|---|
| 相手の性格・今の気持ちの読み | 具体的な処方箋（いつ・何を・どう動くか） |
| 何が起きているかの解説 | 送る文面そのもの |
| 「ここから先はちゃんと視ないと言えない」という線引き | 時期の予測 |

**「答えの手前まで」を無料で渡します。**答えそのものは有料です。
ここを間違えて全部無料で渡すと、誰も買いません。逆に何も渡さないと、誰も信用しません。

## ■ かかるお金

### 固定費

ほぼゼロです。使うサービスは全部無料枠で足ります。

| サービス | プラン | 制限 |
|---|---|---|
| Threads API | 無料 | — |
| LINE Messaging API | 無料 | 返信は無制限。こちらから送る push のみ月200通まで |
| Google スプレッドシート | 無料 | — |
| GitHub Actions | 無料枠 | 個人利用の範囲なら足りる |
| Render（LINEボット） | 無料 | 15分放置で寝るので UptimeRobot（無料）で起こす |
| Streamlit（管理画面） | 無料 | — |

### 変動費

**AI（Claude API）の利用料**が主な費用です。使う量で変わります。

内訳の目安：
- Threads の投稿1本 … 数円程度（Claude のプロジェクトで作る場合はチャットの利用分）
- LINE の自動返信1通 … 数円程度
- 鑑定書1本（約12,000字・8章） … 数十円〜100円程度

**鑑定書が1本売れれば、その月の AI 代は十分に回収できる**規模感です。
ただし相談だけ来て買われない人が増えると、その分は持ち出しになります。

正確な料金は Anthropic の公式ページで最新を確認してください。使ったぶんだけの従量課金です。

### 決済手数料

STORES や Stripe などの決済サービスに、売上の数%（サービスにより異なる）がかかります。

## ■ どれくらい売れるのか（正直な数字）

**表示数と売上は関係ありません。**これは実データで確認済みです。

- 3,154表示の投稿 → 相談に来た人 **1人**
- 86表示の投稿 → 相談に来た人 **1人**

伸びる投稿を作ることより、**深く刺さる投稿を作ること**のほうが重要です。
詳しくは `06_実績と失敗の記録.md` を読んでください。

### 目標の立て方

有料鑑定を実際にすすめた人の数を数えてください。

- 30人にすすめて **3件以上** 売れた → その調子で続ける
- 30人にすすめて **2件以下** → 60人まで様子を見る
- 60人にすすめて **4件以下** → やり方を根本から見直す

これは実際に使っている判断基準です。「なんとなく売れない」で続けないための線引きです。

## ■ あなたが毎日やること

自動化されていない部分だけです。

| 頻度 | やること | 時間の目安 |
|---|---|---|
| 毎日 | 投稿を作ってスプレッドシートに仕込む | 10分 |
| 毎日 | LINE公式アプリを開いて、返信待ちの人に返す（通知は来ません） | 10〜30分 |
| 購入があったら | 詳しい状況を聞く → 鑑定書を作る → 渡す | 1件あたり30〜60分 |
| 週1 | 反応を見て、うまくいった型を確認する | 15分 |

**鑑定書を作る作業も、AI が下書きを全部書きます。**あなたは相手の情報を整理して渡し、
出てきた文章を確認して送るだけです。
