# ターゲットペルソナ

## メインペルソナ

| 項目 | 内容 |
|---|---|
| 年齢 | 25〜40歳 |
| 属性 | 会社員（年収300〜600万）、子育て世代、将来不安組、主婦 |
| 悩み | 給料が上がらない / 時間がない / スキルがない / 何から始めればいいか分からない |　できるだけ楽をして時間もお金もかけずに稼ぎたい
| 願望 | 月+5〜10万の副収入、いずれ独立、楽して稼ぎたい本音もあり |
| 情報源 | X、Threads、YouTube、インスタグラム |
| 既購入経験 | 情報商材、オンラインサロン、Udemy、Brain 、有料note、その他情報商材|

## 深層心理（インサイト）
- 「AIで稼げる」は信じたいが、半信半疑
- 「やってみたが続かない」人が多い
- **再現性・即効性・具体性**に強く反応する
- 「自分にもできそう」と思わせる等身大さが効く
- 嫉妬と憧れの両方を持っている → 軽い口調で中和すると刺さる

## 反応する言葉・嫌う言葉

### 反応する
- 具体的な金額（「30分で7万円」「月50万」）
- ゼロから／知識なし／スキルなし
- ガラ空き市場／今がチャンス
- 主婦が／会社員が（自己投影できる属性）
- 1日◯時間でOK／簡単／自動

### 嫌う・冷める
- 抽象的な精神論（「努力すれば」「本気でやれば」）
- 上から目線・説教
- 嘘っぽい高額収益（月1,000万など現実離れした額）
- 専門用語の羅列
- 売り込み臭の強い投稿

## 市場特性（2026時点）
- AI副業ジャンルは**飽和→淘汰フェーズ**
- 「ツール紹介だけ」では伸びない
- **「AI × 具体的な稼ぎ方」**が伸びる
- 競合タイプ：①ツール紹介系 ②プロンプト配布系 ③稼ぎ方ノウハウ系 ④思想系 ⑤実績公開系
- 推奨ポジション：**③×⑤のハイブリッド**（ノウハウ＋実績）
