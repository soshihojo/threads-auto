# Threads自動投稿ルール集

このフォルダは、Threadsで「AI×稼ぐ系」発信を自動生成するためのルールを蓄積する場所。
新しい知見・分析・フィードバックは随時各ファイルに追記していく。

## 目的
- ターゲット：副業で稼ぎたい層（会社員・主婦・将来不安組）
- 発信ジャンル：AI × 副業・収益化
- 最終ゴール：フォロワー獲得 → リスト化 → 自社商品販売

## ファイル構成

| ファイル | 内容 | 更新頻度 |
|---|---|---|
| `01_persona.md` | ターゲットペルソナ・市場特性 | 中 |
| `02_buzz_patterns.md` | 実際のバズ投稿の分析・型 | 高（事例追加） |
| `03_winning_elements.md` | バズの必勝要素・共通則 | 中 |
| `04_templates.md` | 投稿生成用テンプレート | 高 |
| `05_avoid.md` | 避けるべき表現・罠 | 中 |
| `99_post_archive.md` | 分析した実投稿のアーカイブ | 高（追加のみ） |

## 使い方（投稿生成時）
1. `01_persona.md` でターゲット感覚を再確認
2. `04_templates.md` から型を選ぶ
3. **`03_winning_elements.md` 冒頭の「最重要原則：冒頭フック」を必ず確認**（最優先）
4. `03_winning_elements.md` の必勝要素を最低3つ含める
5. `05_avoid.md` のNG項目をチェック
6. 生成後、`02_buzz_patterns.md` の型と照合して品質確認

## 追記ルール
- 新しいバズ投稿を見つけたら → `99_post_archive.md` に追加 → `02_buzz_patterns.md` で型を抽出
- 自分の投稿で伸びた/伸びなかった結果 → `02_buzz_patterns.md` の末尾に「自社実績」セクションで追加
- 新しいフィードバック・気づき → 該当ファイルに日付付きで追記
