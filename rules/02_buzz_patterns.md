# バズ投稿の型カタログ

実際のバズ投稿から抽出した再現可能な型。新しい型を見つけ次第追記。

---

## 型①：実績数字+AI使用+問いかけ型【最強・エンゲージ率60%級】

### 構造
```
[実績の具体数字（時間×金額）] + [AI使用明示] + [問いかけ or 自慢の中和]
```

### 元ネタ：yatto_gpt（341F・いいね204・リプ86・エンゲージ率59.8%）
> 本日もロゴ制作30分で7万円頂戴しました。4パターン作ったけど、全部AIで完結。これが再現性の高さじゃない？

### ポイント
- 時給換算で衝撃を与える（30分→7万＝時給14万）
- 「本日も」で日常感を出す
- 末尾の問いかけがリプ率25%を生む

---

## 型②：AI擬人化・組織化型【未来感×楽さ】

### 構造
```
[AIを役職・チーム化した表現] + [売上の数字] + [究極の楽さ訴求]
```

### 元ネタ：ai.perm（1,582F・いいね839・エンゲージ率53%）
> 社員ゼロ、AI 6体で会社を回してます。売上は月44万円。Claude Code が COO。研究、分析、ライティング、投稿、品質管理、全部AIがやってる。人間の仕事は『承認ボタンを押すだけ』。

### ポイント
- AIを「6体」「COO」と擬人化する新鮮さ
- ツール名を具体的に出す（Claude Code等）
- 「承認ボタンを押すだけ」で究極の楽さ

---

## 型③：実績+配布フック型【リード獲得最強】

### 構造
```
[時間×金額の実績] + [軽い口調で中和] + [プロンプト/ノウハウ配布フック]
```

### 元ネタ：ai_inform001（344F・いいね145・リプ103・エンゲージ率42%）
> AIツール使って15分くらいで書いたLPから62万円売れた。わーい。このときに使ったLP制作のプロンプトいりますか？（希望者多ければ配布）

### ポイント
- 「わーい」で嫉妬を中和
- 「希望者多ければ」で群衆心理を発動
- リプを強制的に集める設計
- DMリスト獲得の鉄板

---

## 型④：ジャンル別収益リスト型【メニュー化】

### 構造
```
[キャッチー導入] + [ジャンル別の金額リスト3〜4個] + [簡単アピール] + [CTA]
```

### 元ネタ：mako__ai（1,770F・いいね473・エンゲージ率26.7%）
> 始めてよかった！AIで作るBGM動画🎵
> 💰 睡眠BGM → 月100万円
> 💰 作業集中BGM → 月80万円
> 💰 ランニングBGM → 月50万円
> 💰 瞑想BGM → 月20万円
> 1日1本投稿するだけ！「やり方知りたい！」と思ったらいいねしてね👍

### ポイント
- 金額の階段で読まされる
- 「1日1時間でOK」で副業層の時間制約に刺さる
- 絵文字でリスト視認性UP（Threadsで例外的に有効）

## 型⑤：逆張り宣言+ノウハウ無料配布型【拡散型】

### 構造
```
[逆張り or マウント宣言] + [圧倒的実績] + [パクってOK的な無料配布]
```

### 元ネタ：shiro_sns01（22,000F・いいね1.2K・再投稿45）
> マウントとります。Threads1人で7アカ万垢にしました。平均1.5ヶ月です。正直、Threads伸ばすのは驚くほど簡単。やるべきことまとめちゃったので、パクってOKです🥺

### ポイント
- 「マウントとります」のメタ表現で潔さ＝好感
- 「パクってOK」で心理的負債を作る
- 連投スレッドで深掘り
- ※フォロワー多い人向け、初期は使わない

---

## 型⑥：第三者事例+ガラ空き訴求型【自己投影型】

### 構造
```
[身近な第三者の実績] + [簡単さ] + [ガラ空き市場アピール]
```

### 元ネタ：fuji_ai_news（3,300F・いいね116）
> 母親の知り合いの主婦にモニターとしてAI副業を始めてもらったんだけど、初月50万円を稼いでた。1日1時間程度。理由は簡単で、"まだ市場がガラ空き"だから。

### ポイント
- 第三者事例で自慢感を消す
- 「主婦」など投影しやすい属性を使う
- FOMO（乗り遅れ恐怖）を刺激

---

## 型⑦：ストーリーアーク型【ファン化】

### 構造
```
[どん底状況] + [きっかけ・出会い] + [救済・成果] + [メッセージ]
```

### 元ネタ：kitsune_tyan_ai（4,730F・いいね242）
> 日本円の収入が激減し、どん底にいた私を救ってくれたのは、Patreon（海外版note）で世界から届いた『ドル』でした。$3,373（約50万円）。日本で絶望していても、世界（80億人）へ目を向ければ...

### ポイント
- 物語性で共感獲得（拡散より保存・フォロー型）
- 文章力が必要、後回し推奨

---

## 型⑧：断言CTA型【コンバージョン重視】

### 構造
```
[断言フック] + [ゼロからの再現性箇条書き] + [行動喚起CTA]
```

### 元ネタ：wakabayashi_015（6,600F・いいね182・リプ64）
> Threads伸ばしたいなら、正直、僕に絡んだ方が早いです。フォロワーゼロ。知名度ゼロ。他SNSの流入なし。AIスキルなし。

### ポイント
- 「絡んだ方が早い」で行動喚起
- フォロー獲得・DM誘導向き
- いいね数より「行動」を取りに行く設計
