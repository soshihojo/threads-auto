# 投稿生成テンプレート

`02_buzz_patterns.md` の型をすぐ使える穴埋め式に変換したもの。

---

## テンプレ①：実績+問いかけ型

```
[今日も/本日も][作業内容][時間]で[金額]頂きました。
[制作物の数や規模]、全部AIで完結。
これが[再現性/AIの威力]じゃない？
```

### 例
```
本日も記事執筆20分で3万円頂戴しました。
3記事作ったけど、全部Claude完結。
これが時給の壊れ方じゃない？
```

---

## テンプレ②：AI擬人化型

```
[人員ゼロ系の宣言]、AI[数]体で[業務]してます。
売上は[月◯万円]。
[AIツール名]が[役職]。
[業務リスト]、全部AIがやってる。
人間の仕事は『[最小限の作業]』。
```

### 例
```
社員ゼロ、AI 4体で広告運用してます。
売上は月80万円。
ChatGPTがクリエイティブディレクター。
リサーチ、コピー、バナー案、レポート、全部AIがやってる。
人間の仕事は『送信ボタンを押すだけ』。
```

---

## テンプレ③：実績+配布フック型

```
AI使って[時間]で[作ったもの]から[金額]売れた。[軽い感嘆]。
このとき使った[プロンプト/手順]いりますか？
（希望者多ければ配布）
```

### 例
```
AI使って10分で書いたメルマガから38万円売れた。やばい。
このとき使ったメルマガ生成プロンプトいりますか？
（希望者多ければ配布）
```

---

## テンプレ④：ジャンル別収益リスト型

```
[ポジティブ導入]！AIで作る[ジャンル]🎵

💰 [サブカテゴリA] → 月[金額]
💰 [サブカテゴリB] → 月[金額]
💰 [サブカテゴリC] → 月[金額]
💰 [サブカテゴリD] → 月[金額]

[作業の簡単さ]！[時間]でOK💡
「[興味喚起ワード]」と思ったら[CTA]
```

---

## テンプレ⑥：第三者事例型

```
[関係性]の[属性の人]に[何かを]試してもらったんだけど、
[期間]で[金額]稼いでた。
これ、[時間換算]すると[1日◯時間程度]。
理由は簡単で、"[市場の状況]"だから。
```

### 例
```
クライアントの個人事業主にAIで広告運用を任せたんだけど、
初月で売上180万円増えてた。
これ、作業時間で換算すると1日30分程度。
理由は簡単で、"競合がまだAIを使えてない"だから。
```

## テンプレ⑧：断言CTA型

```
[目的]したいなら、正直、[行動]した方が早いです。
[実績条件1]。
[実績条件2]。
[実績条件3]。
[簡潔な権威付け1行]。
```

## 投稿生成時のチェックリスト

生成後、必ず以下を確認：

- [ ] **【最重要】1行目のフックで指が止まるか**（意外性・常識を覆す・衝撃の数字のいずれかが入っているか／普通の挨拶や前置きで始まっていないか）
- [ ] 80〜200文字に収まっているか
- [ ] 必勝要素を3つ以上含んでいるか（金額・AI・時間・再現性・CTA）
- [ ] 1投稿1メッセージになっているか
- [ ] `05_avoid.md` のNG表現を含んでいないか
- [ ] 嘘っぽい高額（月1,000万など）になっていないか
- [ ] ターゲット（副業層）が自己投影できる属性が入っているか
