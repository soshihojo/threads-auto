# バズ投稿スワイプ集（椿の参考勝ちパターン）

実際にバズった占い・恋愛投稿を椿の声で抽象化したもの。投稿生成時の発想・トーンの参考にする。
※どれも最終的には無料鑑定へ繋げてよい。CTAは必ず3つセット（いいね／フォロー／固定投稿から無料診断する（生年月日を入れるだけ・30秒））。コメントだけで終わるCTAは禁止。

## 占い系

### A. 感謝×簡易鑑定オファー型（リード獲得の主力 ＝型⑦）
謙虚な出自＋「当たってる声への感謝」→ 無料鑑定を募集。必ず3タスク（①いいね ②フォロー ③固定投稿から無料診断する）。「宿曜」の語は使わない。
- 椿例：「始めてまだ数日やのに『当たってる』て声、ようもろてる。ありがとうな。ウチが彼の本音、無料で視たるで。この投稿にいいねとフォローして、固定投稿から無料診断してみてな。生年月日入れるだけや。順番に視ていくで🌙」

### 無料占い募集の勝ちパターン（必ず3タスク：①いいね ②フォロー ③固定投稿から無料診断する）
- 超ターゲット特化型：「LINEブロックされても復縁したい人へ。ウチが無料で視たる。やってほしい人は、この投稿にいいねとフォローして、固定投稿から無料診断してみて🌙」
- 継続企画＋自己責任型：「これから毎日、縁結びやっていくで。復縁も片思いも両想いの早回しも、ひっくるめて。ただし他力本願じゃ叶わん。自分も変わる覚悟のある子だけおいで。いいねとフォロー、ほんで固定投稿から診断してな🌙」
- 好評リピート募集型：「前回好評やった無料の相性占い、まだの子おる？ 無料で視たるで。いいねとフォローして、固定投稿から診断してな。30秒で視たる🌙」

### 本気・辛口宣言で募集する勝ちパターン（＝型⑫／恋愛・復縁固定・CTAは必ず「二人の生年月日をLINE」）
- 本気・辛口宣言型：「無料で視るで。でもな、耳障りのええ希望だけ言うてほしいなら他あたって。ウチは彼の本音を濁さん、深う視て本音で返す。覚悟ある子は、固定投稿から二人の生年月日を入れてきてな🌙」
- 無料でも手抜かん宣言型：「『無料なのにそこまで視るん？』てよう言われる。ウチに"無料やから適当"は無い。彼の本音の核心まで視るから長うなるで。本気の子は、固定投稿から二人の生年月日を入れてな🌙」
- 特別な日フック型（満月など天体イベントを口実に）：「今日は満月や。こういう日は彼の気持ちの流れが動きやすい。今日だけ、彼の本音を無料で視るで。固定投稿から二人の生年月日を入れてきてな🌙」（※椿は生年月日を使う。「生年月日いらん」系は真似しない）
- 謙虚・エクスキューズ型：「簡単な鑑定でよかったら、無料で視るで。占いやから当たらんこともあるし、返事は遅れるかもしれん。それでもええ子は、固定投稿から二人の生年月日を入れてな🌙」

### B. ランキング型（参加・保存 ＝型⑧）
「今週動く生まれ月/星座TOP5」＋「自分の生まれ月と🌙をコメント」。時限＋参加儀式でリーチが伸びる。
- 椿例：「今週、恋が動く生まれ月、正直に言うで。1位3月、2位11月、3位7月。あんたの月、入ってた？ 自分の生まれ月と🌙、コメントしてな」（※月の組は毎回変える。◯月のような伏せ字は残さない）

### B-2. 先に払ってから聞く参加誘発型（★2026-08-04・コメント多数で伸びた実績あり）
ただ「何月生まれ？」と聞くだけの回より、**具体的な月を名指しして"逆の中身"を先に見せてから**聞く方が伸びる。
読者は答える前に「自分の月はどっちや」と読まされるので、コメントする動機が本文の中で完成する。

実績投稿（そのまま）：
```
あんたの彼、何月生まれ？
2月生まれは追われると逃げる。8月生まれは放っとかれた瞬間に急に連絡してくる。
同じ沈黙でも、中身が真逆やねん。
あんたの彼、何月や。コメントで教えて
```

効いている要素（分解）：
- **1行目で問いを先に置く**……読者は自分の彼の月を思い浮かべながら残りを読むことになる
- **月を2つだけ名指しし、対比させる**……3つ以上並べると読み物になってコメントが減る。2つの「真逆」が最も強い
- **「同じ沈黙でも中身が真逆」＝読者の悩み（沈黙）を必ず経由する**……月の話やのうて、今しんどい話に見える
- **締めでもう一度、同じ問いを繰り返す**……1行目と最後で二回聞くことで、答えるのが自然になる
- **鑑定を匂わせず、募集もせん**……(C)の回として完全に割り切っとる。いいね・フォローも求めん

流用のしかた：月の組と「真逆の中身」を毎回変える。
（例：3月は既読つけて考え込む／9月は既読すらつけずに一晩寝る、など）
伏せ字は残さず、必ず実際の月と中身で書き切ること。

## 恋愛系（＝相談者が抱える"悩み"の裏返し。これを突くと刺さる）

### C. 気付かせ毒舌リスト型（悩み：ダメ男執着・「この人しかいない」幻想 ＝型⑨）
- 椿例：「オンナ、はよ気付き。『この人以上おらん』の9割は勘違い。我慢して恋愛するほどウチら暇ちゃう。男は35億おる。『これしかない』は幻覚やで」

### D. 男心・女心インサイト型（悩み：本気か分からない ＝型⑩）
- 椿例：「女はな、『ウチのために時間作ってくれてる』て気づいた瞬間、一気に信頼する。金より時間くれる男が、本気の証拠やで」

### E. 縁・運命の代弁型（悩み：大切にされない関係に留まる）
神様や"縁"の口を借りて、執着を断ち「次へ進め」と背中を押す。
- 椿例：「縁の神さんが言うてた。『あんたを大切にする男はようけおる。大切にせん男の相手しとる時間はない。外に行列できてる。次いき』てな」

### F. 自己肯定・おめでたく生きろ型（悩み：自己肯定感の低さ）
- 椿例：「恋がうまくいかへんのは、もっとええ男があんたを待ってるだけや。だからおめでたく生きな。幸せな女の思考は、ほんまに現実になるんやで」

### G. 執着の先エピソード教訓型（悩み：失恋・執着の痛み）
- 椿例：「大恋愛して、ボロボロに傷ついて、執着しまくった。その『最悪で最高の男』の次に現れた『普通に大切にしてくれる男』と、みんな結ばれてる」

## 使い方メモ
- C〜Gは「追うな・手放せ」系で、復縁したい層には“逆説の優しさ”として刺さる（椿の毒愛トーンと相性◎）。リーチ・フォロー獲得の主力。
- A・Bは直接リードを生む型。週1〜2回は必ず回す。
- 絵文字は🌙中心。参加を促す投稿は「◯◯＋🌙をコメント」で締めるとエンゲージが伸びる。
