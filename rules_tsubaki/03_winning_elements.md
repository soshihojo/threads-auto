# 必勝要素（バズの7レバー）

恋愛・占い投稿が伸びる仕組み。毎回どれかを意図的に効かせる。

1. **儀式化したエンゲージ誘導**：🌙やコメント「本音」など低摩擦の行動を、ご利益（視たる）と結びつける
2. **時限の予言**：「今だけ」「◯時間以内」で検証できる予言＋FOMO
3. **セグメント個別感**：生まれ月・宿で分岐し、全員が自分を発見する
4. **一発でわかる声**：関西弁・タメ口・「あんた」呼びで"本物の人"感と親密さ
5. **物語＋教訓**：鑑定エピソード→「当てたからやない、信じて動いたから」で主体性を持たせる
6. **逆説フック**：「〜したいなら読むな」の否定で引く
7. **本音×受け止め（tough love）**：残酷な本音を言い切ってから、最後に背中を押す

## 1行目フックの基本
- 彼の本音／音信不通／既読スルーの核心をいきなり突く
- 読者の状況を名指しする（「既読スルーされて『忙しいんかな』て思てる人」）
- 説明・自己紹介から入らない

## 4指標と仕掛けの対応（毎回どれかを狙う）
| 伸ばす指標 | 仕掛け |
|---|---|
| コメント数 | 鑑定を約束しない参加誘発：「当てはまった子は🌙で教えて」「あんたの彼、何月生まれ？」「どっち派？」 |
| フォロワー数 | フォローの理由を作る：「毎晩視てる」「続きは明日視るで、フォローして待っとき」（型⑬）、無料鑑定3点セットの中のフォロー |
| プロフ閲覧数 | 「無料鑑定の受け方はプロフに書いてるで」等のプロフ誘導（たまに） |
| 無料診断LINE数 | 3点セットCTA（いいね・フォロー・固定投稿から無料診断する）＋「生年月日送るだけでええ」のハードル下げ |

## CTAの基本（★2026-08-13改定：実測313本の突合でDM・固定誘導を全廃）

**締めは「生まれ月をコメントに置いてって」一択。他の締めは全部やめる。**

根拠（313本・リード521件を締めの型ごとに突合した実測）：

| 締めの型 | 本数 | 計views | 獲得リード | 1本あたり |
|---|---|---|---|---|
| 生まれ月をコメント | 67 | 130,851 | **513（全体の98.5%）** | 7.7件 |
| DM誘導 | 61 | 30,794 | 5 | 0.1件 |
| その他のコメント（🌙だけ等） | 36 | 22,529 | 2 | 0.1件 |
| 固定投稿・プロフ誘導 | 80 | 60,853 | **1** | 0.0件 |
| CTAなし | 69 | 19,651 | 0 | 0件 |

- **DM誘導は61本で5件、固定投稿誘導は80本で1件。**この2つで141本＝全体の45%を使て、獲得は6件やった。7月頭にDMが効いた記憶は、その後の61本で否定された。過去の成功体験やのうて、直近の実数で判断する
- **バズと集客は対立せん。**42,019v→55件、8,263v→45件。伸びた投稿でリードも取れとるのは全部この型や。逆に5,519v・5,339vの固定誘導回はリード0。views が出ても、締めが場を移す形なら一件も落ちん
- **「🌙置いてって」だけの抽象CTAも死ぬ。**置くもんが「生まれ月」と明示されてへんと、読者は何を書いたらええか分からん
- 予告締め（「明日視るで」「フォローして待っときな」）は引き続き禁止
- **拡散だけを狙う回も、締めは生まれ月にする。**「鑑定を匂わせない参加誘発」の枠は廃止した。同じ一動作で拡散もリードも取れる以上、分ける意味がない

**ファネル**：投稿 → コメントに生まれ月 → 自動巡回（1時間おき）が1:1で返信 → その返信の中で診断へ誘導 → LINE登録 → 無料鑑定 → 会話 → 有料。
**投稿本文からは診断にもDMにも送らん。**場を移す手続きは、コメント返信という1:1の場でだけやる。

## テーマの配分（★2026-08-13新設：状況別の購入率の実測から）

診断の自己申告と購入を突合した結果、**急性のイベントを抱えとる層ほど買う**：

| 状況 | LINE登録 | 購入率 |
|---|---|---|
| 別れ話の後 | 26 | **11%** |
| 急に冷められた | 25 | 8% |
| 音信不通 | 54 | 7% |
| その他・複雑 | 120 | 6% |
| 片思い | 61 | 6% |
| 復縁したい（一般） | 155 | 4% |

- **購入者33人中13人（39%）が、トークで不倫・既婚に言及しとる。**しかも診断に「不倫」の選択肢が無いので、全部「その他・複雑」に紛れて見えてへんかった。いちばん財布の厚い層が、投稿でもファネルでも一度も名指しされてへん
- 配分は **復縁50% / 不倫・複雑30% / 音信不通・冷め20%**
- 1行目は「復縁したい」みたいな一般語やのうて、**急性イベントの語彙**（別れ話のあと・急に冷めた・音信不通◯ヶ月）を優先する。転換率が倍ちがう

### 不倫・複雑を扱う時の縛り（守らんかったら書かん方がまし）
- 書くのは**状況の名指しだけ**。「誰にも言えん恋をしとる子」「会える曜日が決まっとる恋」「既婚の彼が黙る時、生まれ月でこう違う」
- **禁止**：奥さん・家庭から奪う方法、不倫成就の約束、離婚時期の断定、相手の家庭を悪う言う表現。消契法・プラットフォーム規約・ブランドの三重リスクや
- 立場は常に**受け止める側**。裁かん、焚きつけん、背中を押しすぎん
