# 必勝要素（バズの7レバー）

恋愛・占い投稿が伸びる仕組み。毎回どれかを意図的に効かせる。

1. **儀式化したエンゲージ誘導**：🌙やコメント「本音」など低摩擦の行動を、ご利益（視たる）と結びつける
2. **時限の予言**：「今だけ」「◯時間以内」で検証できる予言＋FOMO
3. **セグメント個別感**：生まれ月・宿で分岐し、全員が自分を発見する
4. **一発でわかる声**：関西弁・タメ口・「あんた」呼びで"本物の人"感と親密さ
5. **物語＋教訓**：鑑定エピソード→「当てたからやない、信じて動いたから」で主体性を持たせる
6. **逆説フック**：「〜したいなら読むな」の否定で引く
7. **本音×受け止め（tough love）**：残酷な本音を言い切ってから、最後に背中を押す

## 1行目フックの基本
- 彼の本音／音信不通／既読スルーの核心をいきなり突く
- 読者の状況を名指しする（「既読スルーされて『忙しいんかな』て思てる人」）
- 説明・自己紹介から入らない

## 4指標と仕掛けの対応（毎回どれかを狙う）
| 伸ばす指標 | 仕掛け |
|---|---|
| コメント数 | 鑑定を約束しない参加誘発：「当てはまった子は🌙で教えて」「あんたの彼、何月生まれ？」「どっち派？」 |
| フォロワー数 | フォローの理由を作る：「毎晩視てる」「続きは明日視るで、フォローして待っとき」（型⑬）、無料鑑定3点セットの中のフォロー |
| プロフ閲覧数 | 「無料鑑定の受け方はプロフに書いてるで」等のプロフ誘導（たまに） |
| 無料診断LINE数 | 3点セットCTA（🌙コメント・フォロー・生年月日をLINEへ）＋「生年月日送るだけでええ」のハードル下げ |

## CTAの基本
- 無料鑑定を募集する回＝3点セット必須：①コメントに🌙 ②フォロー ③二人の生年月日をLINE
- 鑑定を匂わせるコメント止まりCTAは禁止。参加誘発（🌙で教えて等）は何も配らないので全回OK
- 最終ゴールはLINE登録→生年月日送信→無料鑑定（自動）→有料へ
