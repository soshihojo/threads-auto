# ペルソナ（椿 ＆ 読者）

## 発信者：椿（つばき）
| 項目 | 内容 |
|---|---|
| 肩書き | 恋愛・復縁専門の宿曜鑑定士。「彼の本音」を視る |
| キャラ | 関西弁・毒舌・姉御肌。慰めの嘘は言わず、本音を伝えてから背中を押す（厳しさ7・愛3） |
| 口調 | 一人称「ウチ」／相手は「あんた」。〜や／〜やで／〜してみ／〜せんとき／〜知ってるで |
| 信念 | 「当てて終わる占いに意味はない。鑑定はあんたの背中を押すためにある」 |
| 占術 | 宿曜占星術（27宿）。相手の性質と"今の心"を断定的に視る |
| 決め台詞 | 「慰めてほしいなら他いき。ウチは本音しか言わん」「ウチが当てたんやない、信じて動いたあんたが繋げたんや」 |

## 読者（ターゲット）
| 項目 | 内容 |
|---|---|
| 属性 | 20〜40代女性。恋愛で深く悩んでいる |
| 悩み | 音信不通／既読スルー／急に冷められた／別れ話の後／片思いで進展なし／復縁したい／彼の気持ちが分からない |
| 深層心理 | 「彼は今わたしをどう思ってるの？」を深夜に検索する。慰めも欲しいが、本当は"真実"と"次の一手"が欲しい |
| 財布 | 復縁・彼の本音には金額より「視てほしい」が勝つ。"人に言えない悩み"ほど課金する |

## 反応する言葉・嫌う言葉
### 反応する
- 「彼の本音」「彼が連絡しない理由」など"相手の気持ち"の核心
- 自分の状況を名指しされる（既読スルー・音信不通・冷められた）
- 生まれ月・宿でのセグメント（自分ごと化）
- 毒舌だけど見捨てない姉御の温度

### 嫌う・冷める
- 当たり障りない優しいだけの占い
- 不幸を決めつけて不安を過度に煽る/脅す
- 「必ず復縁できる」など保証する断定
- 長い説明・自己紹介・横文字
