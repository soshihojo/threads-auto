# 投稿の型カタログ（店舗オーナー向け）

店舗オーナーの手挙げ（ポスティング/HP相談）を取るための再現可能な型。
※副業層向けの「時給14万」系は使わない。店主は冷める。**集客の現場リアル**で攻める。

---

## 型①：業種特化の反響事例型【手挙げ最強】

### 構造
```
[同業種の具体的な集客結果] + [何をしたか1行] + [軽い問いかけ/手挙げ誘導]
```
### 例
> 大阪の整体院、チラシ撒いても全然来なかったのに、配るエリアと内容を変えただけで予約が月12件増えた。実は「誰に・どこで配るか」で反響は別物。同じこと困ってる人はいいね。

### ポイント
- 業種を明示（自己投影）／地域名を入れる
- 「○○を変えただけ」で再現性を匂わせる
- 末尾で軽く手挙げを誘う（売り込まない）

---

## 型②：常識の逆張り型【スクロールを止める】

### 構造
```
[集客の常識を覆す一言] + [理由・実例] + [気づき]
```
### 例
> ポスティングは「枚数」じゃないです。1万枚ばら撒くより、3千枚を“当たるエリア”に入れる方が反響は出る。枚数で消耗してる店主、めちゃくちゃ多い。

### ポイント
- 1行目で「え？」を作る（必勝要素：冒頭フック）
- 店主の実感に刺さる具体例
- 押し売りゼロで価値だけ置く

---

## 型③：失敗あるある共感型【ファン化】

### 構造
```
[店主がやりがちな失敗] + [なぜダメか] + [じゃあどうするか1行]
```
### 例
> 「ホームページ作ったのに問い合わせが来ない」って相談、めっちゃ多い。だいたい原因は2つ。①スマホで見づらい ②問い合わせ導線が弱い。作って終わりにすると、ただの名刺になる。

### ポイント
- 過去に痛い目を見た経験を代弁→信頼
- 専門家ポジションが自然に立つ
- HP商材への布石になる

---

## 型④：地域×業種リスト型【保存・自分ごと化】

### 構造
```
[地域導入] + [業種別の集客の効きどころ3〜4個] + [問いかけ]
```
### 例
> 大阪で集客に効くチラシの中身、業種で全然ちがう。
> 🍶 飲食 → 「期間限定メニュー＋地図」
> 💇 美容 → 「初回限定＋スタッフ写真」
> 🦴 整体 → 「症状別の悩み＋ビフォーアフター」
> 🏠 リフォーム → 「施工事例＋無料見積」
> 自分の業種が知りたい人はいいね。

### ポイント
- 絵文字リストでThreadsでも視認性UP
- 手挙げ（「知りたい」）を取りに行く設計＝リード検知ワードと連動
- 地域名を必ず入れる

---

## 型⑤：無料オファー直球型【コンバージョン】

### 構造
```
[限定感のある無料オファー] + [対象/条件] + [行動喚起]
```
### 例
> 【大阪の店舗オーナー限定】チラシの反響が出るエリア設計、無料で診断します。「どこに・何枚・どう配るか」を具体的に返します。先着5名。やってみたい人はいいね。

### ポイント
- 「無料」「先着」「限定」で動機づけ
- 手挙げは**いいね**で取る（コメントより圧倒的にハードルが低い）
- 多用厳禁（毎回これだと売り込み臭）。①〜④で価値提供してから時々これ

---

## 型⑥：実体験ショート型【実績◎ 2アポ獲得】★最優先

実際に問い合わせ・アポにつながった勝ちパターン。**コピペせず、この構造を別サービス/別業種に展開する。**

### 構造（90字前後・3〜4行）
```
[1行目: 地域＋自分が何をしている人か（例: 「大阪でチラシ作ってポスティングまで代行しています」）]
[2行目: 自分や身内のリアルな小さな実体験＋具体数字1つ（例: 「実家の石材屋、試しに1,000部配ってみたら数十件の問い合わせ」）]
[3行目: 超低ハードルの手挙げCTA（例: 「〇〇を試してみたい方はいいねください」）]
```
### 元になった勝ち投稿（参考。そのまま使わない）
> 大阪でチラシ作ってポスティングまで代行しています。
> 実家の石材屋、試しに1,000部配ってみたら数十件の問い合わせがありました。
> チラシでの集客を試してみたい方はいいねください。

### なぜ効いたか（抽象化＝ここを守る）
1. **短い**（最後まで読める。長文は離脱）
2. **1行目で「地域＋何屋か」を即提示** → 見た人が一瞬で自分ごと化
3. **身内/自分のリアルな実体験** → 親近感・嘘くさくない（広告っぽくない）
4. **具体数字を1つだけ**（盛らない）→ 再現性と説得力
5. **超低ハードルCTA**（いいね/軽いコメント）→ 手を挙げやすい
6. **売り込み・自慢ゼロ**の謙虚トーン（「試しに」「試してみたい方」）

### 4サービスへの展開イメージ（数字や事例は毎回変える）
- HP: 「知り合いの〇〇店のHPを作り直したら、問い合わせが月◯件増えた。気になる人いいね」
- 広告: 「初めてInstagram広告を◯円だけ回したら、来店が◯件。試したい人はいいね」
- SNS運用: 「友人の店のInstagram、投稿の型を変えただけで保存が◯倍。やり方知りたい人いいね」

※ 全タイプ共通の文末CTAルール：
1. 必ず「いいね」で統一（コメント・DM・「いる？」等の問いかけは使わない。手挙げのハードルを最小化）
2. **何に対するいいねかを明示**する。「試してみたい方はいいね」だけはNG。「チラシでの集客を試してみたい方はいいね」「HPの無料診断を受けたい方はいいね」のようにサービスを入れる
3. その前提として、本文で「自分が何を提供している人か」を伝える（勝ち投稿は1行目「大阪でチラシ作ってポスティングまで代行しています」が効いた）
4. 「いいねが多ければ次に投稿します」など**実行しない約束は禁止**

## 型の使い分け早見表

| 目的 | 推奨の型 |
|---|---|
| 手挙げ（リード獲得） | 型①④⑤ |
| 拡散・スクロール停止 | 型②④ |
| 共感・ファン化・専門家化 | 型③ |
| 直接オファー | 型⑤（頻度は週1〜2まで） |

## 投稿配分の目安（売り込み臭を出さない）
- 価値提供（型①〜④）: 8割
- 直接オファー（型⑤）: 2割
