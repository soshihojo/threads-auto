# ターゲットペルソナ（店舗オーナー）

## メインペルソナ

| 項目 | 内容 |
|---|---|
| 属性 | 地域の店舗・小規模事業者のオーナー（飲食/美容/整体・治療院/工務店・塗装/学習塾/クリニック等） |
| 年齢 | 30〜55歳。現場プレイヤー兼経営者が多い |
| 商圏 | 店舗から半径数km〜市区町村レベルの地域密着 |
| 悩み | 新規客が増えない / チラシやSNSを試したが反響が出ない / Web集客のやり方が分からない / 時間がない |
| 願望 | 安定して新規客を獲得したい、広告費をムダにしたくない、現場に集中したい |
| 情報源 | Instagram、Threads、YouTube、知人の紹介、業者からの営業 |
| 予算感 | 集客に月数万〜数十万は出せるが「効果が読めないもの」には慎重 |

## 深層心理（インサイト）
- 「集客＝センスや運」だと思っていて、**仕組みで増やせる**と知らない
- 過去に広告/制作会社で**痛い目を見ている**（高い・効果不明・放置された）
- 専門用語・横文字に**身構える**。現場の言葉で話すと安心する
- 「同業がやって伸びた」事例に最も動く（自分の業界の話に反応）
- **失敗したくない**が先に立つ。だから「無料で診断」「まず反響を出す」の入口に乗りやすい

## 反応する言葉・嫌う言葉

### 反応する
- 「チラシ／ポスティングの反響が○倍」など**具体的な集客数字**
- 「○○屋さんが」など**自分と同じ業種**の事例
- 「広告費をムダにしない」「やってみてダメなら」のリスク低減
- 「現場に集中できる」「ほっといても問い合わせが来る」
- 地域名（大阪・梅田・難波 等）が入っていて自分ごと化できる

### 嫌う・冷める
- 横文字とマーケ用語の羅列（CV、CPA、ファネル…）
- 「Webの時代です」的な抽象論・上から目線
- いきなりの売り込み・高額提示
- 現実離れした成功話（「1ヶ月で売上10倍」など胡散臭い）
- AI・自動化を前面に出しすぎる（店主には響かない。裏方に留める）

## 戦略メモ
- **出口商品**：ポスティング（フロント・前金/外注）→ HP制作（買い切り）→ AI問い合わせ対応（月額）
- **Threadsの役割**：地域＋業種の集客リアルを発信し、「やってみたい/相談したい」の手挙げを取る
- **ジオは配信不可**：本文の地域ワード＋位置タグでローカル露出を取りにいく
- **未検証**：そもそも店舗オーナーがThreadsに居るか・反応するかは要検証。手挙げ数で判断する
