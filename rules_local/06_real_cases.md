# 実話アーカイブ（実績として語ってよいのはここにある実話のみ）

## 絶対ルール
1. **自分（自社）の実績・事例として語ってよいのは、このファイルの実話だけ。**
2. 数字・業種・地域を勝手に変えたり、新しい事例を作ったりしない（捏造禁止）。
3. ただし**同じ実話を、フック・教訓・文体・見せ方を変えて何度でも使ってよい**（推奨）。
4. 実話を使わない投稿は「一般論」として書く（「よくあるのが…」「〜な店は…しがち」）。一般論では自分の実績と主張する具体数字を出さない。

## 実話一覧

### 実話A：石材屋（大阪・実家）× ポスティング
- 事実: 実家の石材屋。チラシを作って1,000部試しに配布 → 数十件の問い合わせ。
- 切り口の例: 「身内で試した」「たった1,000部」「チラシは枚数じゃない」「初めての挑戦」
- 備考: 勝ち投稿（2アポ獲得）の元ネタ。鉄板。

### 実話B：整体院（奈良）× ポスティング
- 事実: 5,000部配布 → 回数券の成約11件。
- 切り口の例: 「問い合わせでなく成約まで出た」「回数券＝リピート前提の客がチラシで取れた」「整体院×チラシの相性」

### 実話C：設備屋（岡山）× ポスティング【ROI最強】
- 事実: 約300,000円の予算で20,000部配布 → 合計6,500,000円の受注。
- 切り口の例: 「30万円が650万円になった」「チラシの費用対効果」「BtoB寄りの業種でもチラシは効く」「単価が大きい商売ほどチラシ向き」

### 実話D：塗装店（兵庫）× HPリニューアル
- 事実: HPをリニューアル → 公開後2日で新規問い合わせが入るようになった。
- 切り口の例: 「公開2日で動いた」「古いHPは入口で損してる」「リニューアル前後の差」「塗装店×HPの相性」

### 実話E：石材屋（宮崎）× HPリニューアル＆SNS運用
- 事実: HPリニューアル → 公開2週間で新規問い合わせ。SNS運用はフォロワー300人で新規問い合わせ3件。
- 切り口の例: 「フォロワー300人でも問い合わせは取れる」「フォロワー数と売上は別物」「HPとSNSの合わせ技」「地方（宮崎）でも効く」

## 変奏のしかた（同じ実話を飽きさせない）
