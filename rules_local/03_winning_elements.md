# バズ・反応の必勝要素（店舗オーナー向け）

投稿生成時、最低3つは含める。

## 🚨 最重要原則：冒頭フックが全てを決める
高速スクロールの中で、**1行目（最初の20〜40文字）で指を止められなければ読まれない**。
店主向けの良いフックは以下のどれか：

- **業種＋意外な結果**：「整体院、チラシ撒いても来なかったのに…」
- **常識の否定**：「ポスティングは枚数じゃない」「HPは作って終わりだと名刺」
- **店主の本音代弁**：「“問い合わせ来ない”って相談、めっちゃ多い」
- **具体数字**：「予約が月12件増えた」「3千枚で反響が出た」
- **地域名で自分ごと化**：「大阪で集客に効くチラシは…」

### NGなフック
- ❌「こんにちは。今日は集客について」
- ❌「Webマーケティングの重要性について」
- ❌ 前置き・自己紹介から入る

## 必勝要素リスト
1. **業種の明示**（飲食/美容/整体/工務店…自己投影させる）
2. **地域名**（大阪/梅田/難波…ローカル露出＆自分ごと化）
3. **具体的な集客数字**（件数・倍率・金額）
4. **再現性の示唆**（「○○を変えただけ」）
5. **リスク低減**（無料/まず診断/ダメなら）
6. **現場の言葉**（横文字を避ける）
7. **軽い手挙げ誘導**（「いる？」「知りたい人？」）

## 投稿前チェック
1. 1行目で指が止まるか？
2. どの業種・地域の話か明確か？
3. マーケ用語で店主を置いてけぼりにしてないか？
4. 売り込み臭が強すぎないか？（価値提供が先か）
